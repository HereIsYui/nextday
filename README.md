## 背景

历一百五十四载，仲春之月，赤焰裂空，有星如斗自霄汉坠。其声震若雷霆，光耀三百里。大地坼裂，陆分九块，沧海倒灌，火泉迸涌。瘴疠饥馑相继而至，饿殍塞川，万姓流离。昭帝减膳撤乐，发仓廪、开武库，欲以人力抗天灾。


然灾异未已。九域初分之际，忽有玄铁巨塔破土而出，各镇洲陆腹心。其高千仞，镌诡纹如蝌蚪，昼夜发散赤芒。地隙间魔物如潮涌出，青面獠牙，食人噬魂。九洲自此隔绝，音讯不通，遂称“绝域之年”。


越十载，蜀中夜有白虹贯紫微。有山人自青城出，素衣悬剑，眸含星斗。世人谓之“蜀道圣”。圣者踏虚而行，剑光过处妖首滚落，授《降魔要术》三十六卷于遗民。后独登天柱峰，结九九八十一日道印，取心头血为引，终封九渊裂隙。魔物哀嚎震天，塔芒尽敛。


圣临去作谒：“封印千载，慎守勿失。”遂化虹而去。百载后，天降金莲，仙乐缥缈，圣者飞升之事始验。


今圣历千一百四十五年，幽州塔基现裂三寸，夜有呜咽声自地脉传来。守塔人见塔顶赤芒复萌，急以朱砂符镇之——然裂隙深处，似有金瞳乍睁。
