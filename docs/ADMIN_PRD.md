# 《择日飞升：九塔封魔》GM 后台产品需求 v0.2

## 一、定位

本文定义运营和客服后台的 MVP 产品需求，用于支撑玩家查询、订单处理、补偿、公告、配置发布、日志审计、封禁和风控处理。

后台必须遵循：

- 最小权限。
- 全操作留痕。
- 高价值操作审批。
- 付费资产不允许无审计变更。
- 查询和处理分离，避免客服误操作。

## 二、角色权限

| 角色 | 权限 | 禁止 |
| --- | --- | --- |
| 客服 | 查询玩家、订单、邮件、基础日志 | 发放高价值道具、改货币 |
| 运营 | 公告、活动、补偿草稿、数据看板 | 直接改订单状态 |
| 高级运营 | 补偿审批、封禁、解封、回滚交易 | 绕过审批发付费仙玉 |
| 技术管理员 | 配置回滚、数据修复、补单 | 无日志操作 |
| 审计员 | 查看操作日志和报表 | 修改玩家数据 |

## 三、后台模块

| 模块 | 功能 |
| --- | --- |
| 玩家查询 | 基础信息、境界、背包、货币、宗门、状态 |
| 订单中心 | 订单查询、回调日志、补单、退款标记 |
| 抽卡查询 | 抽卡历史、保底、随机种子摘要 |
| 战斗日志 | PVP、Boss、九塔战报查询和回放 |
| 任务活动 | 任务进度、活动参与、奖励领取状态 |
| 宗门管理 | 成员、仓库日志、职位变更、宗门纠纷 |
| 交易风控 | 成交记录、异常价格、冻结和回滚 |
| 邮件补偿 | 单人、分组、全服邮件和附件 |
| 公告管理 | 维护、活动、概率、规则调整公告 |
| 配置发布 | 草稿、校验、灰度、上线、回滚 |
| 封禁风控 | 风险查询、收益延迟池、人工审核、冻结、解冻、封禁 |
| 审计日志 | GM 操作、审批、前后值 |

## 四、玩家查询

查询条件：

- 玩家 ID。
- 角色名。
- 鱼排用户 ID。
- 订单号。
- IP / 设备摘要。
- 宗门 ID。

展示信息：

- 基础信息和状态。
- 修行进度、当前章节、新手保护。
- 货币余额和最近货币流水。
- 背包高价值道具。
- 抽卡、订单、邮件、PVP、九塔贡献摘要。
- 风控标记和处理记录。

## 五、订单中心

订单状态流：

`created -> pending -> paid -> delivered`

异常状态：

`failed`、`refunded`、`manual_review`。

补单要求：

- 只允许补 `paid` 未 `delivered` 的订单。
- 必须核验鱼排订单号、玩家 ID、商品、积分、幂等键。
- 补单需要技术管理员或高级运营审批。
- 补单后写订单日志、货币日志、GM 操作日志。

## 六、补偿邮件

补偿类型：

| 类型 | 范围 |
| --- | --- |
| 个人补偿 | 单个玩家 |
| 分组补偿 | 州、阵营、宗门、活动参与者 |
| 全服补偿 | 全服玩家 |

补偿流程：

1. 创建补偿草稿。
2. 选择模板和范围。
3. 配置附件奖励组。
4. 系统校验禁止物品。
5. 审批。
6. 分批发送。
7. 记录领取状态。

禁止通过后台补偿发放：

- 限定本命法宝本体。
- 九大古宝本体。
- 全服贡献倍率。
- PVP 伤害倍率。
- 未核验订单对应的付费仙玉。

## 七、公告与概率公示

公告类型：

- 维护公告。
- 活动公告。
- 概率公示。
- 规则调整。
- 风控说明。
- 纪元结算公告。

公告必须支持：

- 预发布时间。
- 可见范围。
- 生效 / 失效时间。
- 关联配置版本。
- 撤回和修订记录。

概率公示必须展示卡池、消耗、概率、保底、重复转化和继承规则。

## 八、配置发布

配置发布流程：

1. 策划编辑草稿。
2. 自动校验字段、概率、奖励禁止项。
3. 测试环境验证。
4. 生成变更摘要。
5. 审批上线。
6. 灰度或全服发布。
7. 异常时回滚。

校验项：

- 概率是否合计正确。
- 奖励是否含禁止物品。
- VIP / 月卡便利是否突破上限。
- 绑定仙玉是否误入限定池。
- 九大古宝池是否混入非古宝结果。
- 活动是否支持异步参与。

## 九、风控处理

处理动作：

| 动作 | 说明 |
| --- | --- |
| 标记观察 | 不影响玩家，记录风险 |
| 收益延迟 | 奖励暂缓发放 |
| 交易冻结 | 冻结交易和物品 |
| PVP 收益归零 | 对异常战斗生效 |
| 回滚收益 | 回收异常所得 |
| 临时冻结 | 限制登录或交易 |
| 封禁 | 严重违规处理 |

所有处理必须有原因、证据、范围、操作者和申诉入口。

脚本行为处理边界：

- 普通脚本点击不作为直接封禁理由。
- 普通领取、普通探索、洞府收菜只做行为记录和限频。
- PVP、九塔贡献、交易行、宗门仓库、抽卡订单命中异常时，可进入收益延迟池。
- 免费账号调用月卡托管队列、伪造批量上限、伪造策略槽位时，后台应能看到对应越权记录。

风控查询能力：

| 能力 | 说明 |
| --- | --- |
| 玩家风险画像 | 风险分、命中规则、近期接口路径、操作间隔、设备 / IP 摘要 |
| 风控记录列表 | 按风险类型、处理状态、玩法、时间筛选 |
| 收益延迟池 | 查看暂缓奖励、关联行动、贡献、交易或战斗记录 |
| 人工审核 | 发放、回滚、解除标记或升级处理 |
| 处理留痕 | 记录操作者、原因、前后状态、规则版本 |

## 十、后台验收

- 客服能查询玩家、订单、抽卡、战斗、邮件和基础日志。
- 订单补单不能重复到账。
- 补偿邮件不能发放禁止物品。
- 配置发布能校验九大古宝池、绑定仙玉、排行奖励和月卡 VIP 边界。
- 封禁、回滚、补偿、配置发布都有审批和 GM 操作日志。
- 风控后台能查询脚本行为风险分、越权调用、收益延迟池和人工审核记录。
