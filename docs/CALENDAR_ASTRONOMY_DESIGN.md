# 《择日飞升：九塔封魔》择日与天象设计 v0.1

## 一、定位

择日系统为每日轻决策系统，用少量选择影响突破、炼丹、炼器、修塔、破塔、洞府和探索。它提供修仙味道和策略优化，但不能让玩家为了固定时间上线。

核心原则：

- 天象每日生成，全天有效，玩家任意时间可使用。
- 天象影响成功率、品质、资源效率和特殊事件概率，不直接决定全服胜负。
- 月卡、VIP 和九大古宝可提供便利或保存能力，但不叠成必成。

## 二、天象生成

服务器每日生成 3 个公共天象和 1 个个人小天象。

| 类型 | 说明 | 影响 |
| --- | --- | --- |
| 公共天象 | 全服共享 | 九州事件、九塔、公共 Boss |
| 州域天象 | 每州独立 | 采集、秘境、资源点 |
| 个人小天象 | 玩家个人 | 炼丹、炼器、突破、修炼 |

天象品质分为平、吉、大吉、凶、异象。凶象不是纯负面，应提供风险收益。

## 三、天象类型

| 天象 | 倾向 | 效果 |
| --- | --- | --- |
| 青阳初升 | 修炼 | 挂机修为、气血精元轻微提高 |
| 紫气东来 | 突破 | 大境界突破成功率提高 |
| 丹霞满炉 | 炼丹 | 炼丹成功率和品质上限提高 |
| 星火照器 | 炼器 | 淬炼稀有词条概率提高 |
| 白虹贯斗 | 战斗 | Boss 和秘境伤害轻微提高 |
| 玄阴蔽月 | 魔道 | 破封、魔染、九渊材料收益提高 |
| 金莲映塔 | 仙道 | 镇封、净化、功德收益提高 |
| 地脉回潮 | 洞府 | 灵田、聚灵阵、派驻收益提高 |
| 天狗食日 | 凶象 | 战斗难度提高，但稀有材料概率提高 |
| 九星连珠 | 异象 | 多玩法小幅增益，出现概率极低 |

## 四、择日行为

玩家每日可选择 1 个主要择日目标。

| 目标 | 适用玩法 | 结果 |
| --- | --- | --- |
| 择日修炼 | 挂机、离线 | 提高个人修为收益 |
| 择日突破 | 大境界突破 | 提高成功率，但不突破保底上限 |
| 择日炼丹 | 炼丹 | 提高成功率和品质分布 |
| 择日炼器 | 炼器 | 提高稀有词条概率 |
| 择日镇塔 | 九塔仙盟行为 | 提高个人镇封效率，不提高全服贡献倍率 |
| 择日破塔 | 九塔魔宗行为 | 提高个人破封效率，不提高全服贡献倍率 |
| 择日探索 | 九州探索 | 提高州特色材料概率 |

月卡提供每日择日刷新次数。刷新只改变可选天象，不提高最终奖励倍率。

## 五、数值边界

| 效果 | 常规上限 |
| --- | ---: |
| 修为收益 | +5%-10% |
| 突破成功率 | +5%-10% |
| 炼丹成功率 | +5%-12% |
| 丹药品质权重 | 上品及以上权重提高，不保证无瑕 |
| 炼器稀有词条 | +3%-8% |
| 探索材料概率 | +5%-10% |
| 九塔个人效率 | +5%-10%，不提高全服贡献倍率 |

天象、丹药、古宝和月卡加成采用软上限。突破相关加成不能叠成 100% 必成，仍受劫气保底系统控制。

## 六、九大古宝联动

天机星盘每日可保存 1 个有利天象，用于突破、炼丹或炼器。保存天象遵守以下限制：

- 保存天象不作用于 PVP。
- 保存天象不跨周累计。
- 保存天象与月卡刷新不叠成额外次数上限。
- 保存天象不能绕过突破材料和丹炉丹阶限制。

## 七、异常与兜底

| 情况 | 处理 |
| --- | --- |
| 玩家当天未上线 | 天象不补发，但不影响主线参与 |
| 服务器低活跃 | NPC 兜底推进主线，不吃玩家天象加成 |
| 凶象导致失败 | 失败返还按原玩法规则处理 |
| 天象配置错误 | 按配置版本回滚或补偿 |

## 八、验收场景

- 玩家任意时间上线都能使用当日天象。
- 月卡刷新只减少选择成本，不提高最终奖励倍率。
- 天机星盘保存天象不作用于 PVP。
- 突破加成不能叠成无条件必成。
- 九塔天象不直接提高全服贡献倍率。
