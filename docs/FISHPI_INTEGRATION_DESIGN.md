# 《择日飞升：九塔封魔》鱼排接入设计 v0.3

## 一、定位

本文定义后期接入鱼排能力的设计，包括 OAuth 登录绑定、积分余额查询、积分扣减、订单回调、月卡购买、仙玉兑换、VIP 等级查询和异常补单。开发期使用模拟接口，正式接入时替换为鱼排真实能力。

核心原则：

- 鱼排积分是外部资产，所有扣减和到账必须幂等、可查、可补单。
- 游戏只读取鱼排 VIP 等级和有效期，不写入鱼排官方福利。
- 月卡使用鱼排积分购买。
- 仙玉充值使用鱼排积分兑换。
- 绑定仙玉不能抽限定本命法宝池和九大古宝专属池。
- 九大古宝专属池当前只能通过月卡赠抽或九大古宝残页合成抽取，付费仙玉直抽仅作为后期预留入口。

## 二、接入能力

| 能力 | 用途 | MVP 状态 |
| --- | --- | --- |
| OAuth 登录 | 绑定鱼排账号 | 模拟 / 预留 |
| 积分余额查询 | 展示可购买能力 | 模拟 / 预留 |
| 积分扣减 | 购买月卡、兑换仙玉 | 模拟 / 预留 |
| 订单回调 | 确认扣积分成功 | 模拟 / 预留 |
| VIP 查询 | 读取等级和有效期 | 模拟 / 预留 |
| 订单对账 | 处理异常和补单 | 后台预留 |

## 三、账号绑定流程

1. 玩家点击绑定鱼排账号。
2. 游戏服务生成 OAuth 跳转地址。
3. 玩家在鱼排完成授权。
4. 鱼排回调授权码。
5. 游戏服务换取鱼排用户标识。
6. 写入 `fishpi_user_id`。
7. 返回绑定成功。

绑定规则：

- 一个游戏账号只能绑定一个鱼排账号。
- 一个鱼排账号只能绑定一个游戏账号。
- 解绑需要客服审核，避免订单归属纠纷。
- 绑定、解绑、重新绑定必须写安全日志。

## 四、积分购买月卡流程

1. 玩家选择小月卡或大月卡。
2. 游戏创建订单，状态为 `created`。
3. 游戏请求鱼排扣减积分。
4. 订单进入 `pending`。
5. 鱼排回调扣减结果。
6. 游戏校验签名、订单号、玩家、积分金额、幂等键。
7. 校验成功后订单变为 `paid`。
8. 发放月卡权益和立即仙玉，订单变为 `delivered`。
9. 写订单日志、货币日志、月卡记录。

月卡商品：

| 商品 | 积分 | 到账 |
| --- | ---: | --- |
| 小月卡 | 1024 | 立即 124 仙玉，每日 30 仙玉，九大古宝每日 1 抽 |
| 大月卡 | 2048 | 立即 248 仙玉，每日 60 仙玉，九大古宝每日 2 抽 |

## 五、积分兑换仙玉流程

兑换规则需配置化：

| 字段 | 说明 |
| --- | --- |
| product_id | 商品 ID |
| fishpi_point_cost | 积分消耗 |
| paid_jade_amount | 付费仙玉 |
| first_bonus | 首充或活动加成，可为空 |
| valid_from / valid_to | 生效时间 |

限制：

- 兑换获得的是付费仙玉。
- 付费仙玉可抽限定本命法宝池，可购买外观、称号、便利类和收藏类商品。
- 九大古宝专属池当前不允许付费仙玉直接抽取；预留入口只标记为未开放，不扣仙玉、不出结果、不计保底。
- 仙玉不可兑换回鱼排积分。
- 订单异常时只能按订单核验补发，不手工凭截图发放。

仙玉兑换包建议：

| 商品 | 鱼排积分 | 付费仙玉 | 附加赠送 |
| --- | ---: | ---: | --- |
| 小袋仙玉 | 1024 | 1024 | 少量绑定仙玉 |
| 中袋仙玉 | 4096 | 4096 | 绑定仙玉、常驻券 |
| 大袋仙玉 | 10240 | 10240 | 绑定仙玉、外观券 |
| 玄玉匣 | 32768 | 32768 | 绑定仙玉、外观券、称号进度 |
| 太初玉匣 | 65536 | 65536 | 绑定仙玉、外观券、纪元收藏材料 |

大额商品不赠送额外付费仙玉。附加赠送不能进入限定本命法宝池和九大古宝专属池，避免破坏 10 万到 50 万积分毕业模型和抽卡成本预期。当前模型中，九大古宝进度由月卡赠抽和残页合成承接，不由仙玉包直接承接。

## 六、VIP 查询

游戏只读取：

- VIP 等级。
- 有效期。
- 鱼排用户 ID。
- 查询时间。

游戏内福利：

- VIP1、VIP2 低于小月卡便利。
- VIP3 可等同小月卡便利。
- VIP4 可高于小月卡但不得高于大月卡。
- VIP 不发付费仙玉。
- VIP 不提供九大古宝专属池抽取次数。

VIP 查询缓存：

- 建议缓存 5-30 分钟。
- VIP 到期后下次查询或缓存过期时刷新。
- 查询失败时保留短时间旧状态，避免玩家权益闪断。

## 七、回调与安全

回调校验：

- 签名。
- 时间戳。
- 随机串。
- 鱼排订单号。
- 游戏订单号。
- 玩家 ID。
- 积分金额。
- 商品 ID。
- 幂等键。

重复回调：

- 如果订单已 `delivered`，直接返回成功，不重复到账。
- 如果订单为 `paid` 但未到账，尝试继续发放。
- 如果订单金额或商品不一致，进入人工审核。

安全要求：

- 不在客户端保存鱼排敏感凭证。
- 扣积分必须由服务端发起。
- 回调原文摘要保存到订单日志。
- 付费仙玉变更必须写货币日志。

## 八、异常处理

| 异常 | 处理 |
| --- | --- |
| 扣积分失败 | 订单标记 failed，不发权益 |
| 回调超时 | 订单保持 pending，后台可查询 |
| paid 未 delivered | 后台补单 |
| delivered 后重复回调 | 幂等返回成功 |
| 金额不一致 | manual_review |
| 玩家绑定变更 | 暂停订单处理，人工审核 |
| VIP 查询失败 | 短时保留旧缓存，记录告警 |

## 九、对账

每日对账内容：

- 游戏订单数。
- 鱼排扣积分成功订单数。
- paid 未 delivered 订单。
- delivered 但鱼排侧缺失订单。
- 商品金额不一致订单。
- 退款或撤销订单。

对账差异必须进入后台处理，不自动发放高价值权益。

## 十、验收场景

- 同一鱼排回调重复发送不会重复到账。
- paid 未 delivered 订单可以后台补单。
- 月卡购买后立即仙玉、每日仙玉、古宝赠抽正确发放。
- VIP 查询只影响游戏内便利和绑定福利，不发付费仙玉。
- 绑定仙玉不能抽限定本命法宝池和九大古宝专属池。
- 付费仙玉不能直接抽九大古宝；预留入口返回未开放，不扣费、不计保底。
- 鱼排积分扣减失败时游戏不发放权益。
- 10 万到 50 万积分消费可通过月卡、仙玉兑换包、限定本命法宝池、外观、称号、宗门外观和收藏册形成长期毕业目标；九大古宝以月卡赠抽和残页合成为当前入口，不提高全服贡献倍率。
