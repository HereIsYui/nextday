# 《择日飞升：九塔封魔》游戏设计文档 v1.18

## 一、游戏概述

《择日飞升：九塔封魔》是一款多人同服文字/MUD 挂机修仙游戏。一个服务器代表一个纪元，完整通关周期目标约为现实时间 1 年。玩家共同推进九州剧情、九塔封印、仙魔阵营与最终魔王战。

玩家开局选择练气或炼体，后期选择成仙或成魔。玩家行为会影响服务器后续剧情，例如重封封印塔、攻破封印塔、改变九州生态和魔王形态，但最终魔王必定出世。

## 二、世界观

圣历一千一百四十五年，幽州玄铁塔基裂开三寸，九渊深处金瞳复睁。千年前蜀道圣以心头血封印九渊，令九洲隔绝而暂保人间。

如今封印将破，玩家作为守塔人后裔、宗门修士、炼体武者或九渊信徒，在同一服务器纪元中参与九洲命运。成仙者试图重封九塔，成魔者试图攻破封印、吞噬九渊。无论哪条道路，最终都将迎来魔王临世。

## 三、核心体验

- 挂机修行：离线与在线都能积累灵力、气血精元和资源。
- 择日行动：根据天象安排突破、炼丹、炼器、修塔、破塔。
- 多人同服：九州、九塔、魔潮、阵营剧情由全服玩家共同推进。
- 仙魔分流：成仙与成魔都拥有完整成长线和终局目标。
- 长线纪元：服务器按约 1 年节奏推进至最终魔王战。

## 七、全服进度

全服目标按有效活跃人数动态调整，保证服务器约 1 年完成纪元。

- 有效人数：近 7 日登录至少 3 天，且完成修行、战斗、捐献或阵营任务。
- 全服目标值 = 基础值 × 人数系数 × 章节系数。
- 人数系数建议：`max(0.35, 有效人数^0.65 / 标准人数^0.65)`。
- 每章设置最短开放日、推荐完成日、保底推进日，防止大服快进或小服卡死。

## 八、九州大地图与新手追赶

九州是服务器共享大地图，不是单人副本列表。每个州都是全服可交互区域，玩家在州内探索、采集、护送、镇塔、破塔、驻守、建设灵脉或污染地脉，共同改变该州后续剧情和资源生态。

地图术语约定：

- “九州”用于玩家可交互的大地图、系统、事件和玩法。
- “九洲”仅保留在古文风背景叙述中，用于表现旧时代称谓。
- 互动大地图九州固定为：冀州、兖州、青州、徐州、扬州、荆州、豫州、梁州、雍州。
- “幽州”作为冀州北境旧称保留在背景叙事中，系统玩法统一使用“冀州”。

追赶衰减与保护：

- 玩家达到当前章节推荐境界后，追赶加成在 3-7 天内逐步衰减至 0。
- 新账号前 7 天获得新手保护：离线收益上限提高、低阶突破材料保底、低阶秘境失败返还部分次数。
- 新手保护期间不能被高阶玩家直接压制；跨境界冲突采用镜像战力或贡献折算。
- 新手参与九塔战时进入“新手贡献池”，按境界归一折算贡献，保证有奖励但不能刷全服胜负。
- 新手加成优先服务留存和追赶，不服务冲榜、阵营翻盘和付费放大。

## 九、仙魔剧情

| 行为 | 全服影响 |
| --- | --- |
| 仙修重封塔 | 降低魔染，提高民望和灵脉 |
| 魔修攻破塔 | 提高魔染，增强魔宗收益 |
| 多塔重封 | 魔王以裂封形态出世 |
| 多塔攻破 | 魔王以九渊魔主形态出世 |
| 仙魔拉锯 | 触发双相魔王，最终战目标分裂 |

最终魔王必定出世。玩家改变的是世界状态、魔王形态、阵营优势和结局分支。

阵营选择规则：

- 化神 / 神躯阶段正式选择成仙、成魔或继续散修。
- 化神前可自由参与基础阵营任务，但不锁定终局路线。
- 成仙、成魔后可转阵营，但需要完成转道任务、支付资源、清除部分阵营声望，并有 14 天冷却。
- 宗门立场与玩家阵营冲突时，玩家不能参与该宗门的阵营集结。
- 散修可参与九塔和 PVP，但结局奖励偏纪元积分、资源和中立称号，不获得仙魔专属终局称号。

## 十、九塔争夺、阵营规则与公共事件

九塔争夺是多人同服的主线公共玩法。每座封印塔全天开放行动提交，玩家随时投入镇封、破封、驻守和补给行动。日结和周结只负责自动结算，不要求玩家在结算时在线。

阵营任务分工：

| 阵营 | 核心目标 | 主要任务 |
| --- | --- | --- |
| 仙盟 | 重封九塔，降低魔染 | 镇封、修塔、净化、护送、守塔 |
| 魔宗 | 攻破封印，提高魔染 | 破封、污染、袭塔、献祭、引魔 |
| 散修盟 | 维持生存和利益平衡 | 中立资源、情报、雇佣、调停、奇遇 |

贡献拆分为三类：

- 个人贡献：用于个人奖励、排行、称号和周常结算。
- 阵营贡献：用于每日结算、周结算和阵营阶段胜负。
- 塔状态贡献：只改变封印塔完整度、镇封度、破封度、魔染度等全服状态。

贡献平衡规则：

- 贡献按境界分段归一，高等级玩家效率更高，但不能完全吞掉低等级玩家奖励。
- 低等级玩家完成护送、补给、修复阵眼、清理低阶魔物等任务，也能获得有效贡献。
- 阵营人数失衡时，弱势阵营获得任务刷新、NPC 支援和贡献系数补偿，但不直接获得胜利。
- 有效贡献需要账号绑定、活跃门槛和境界门槛；同设备、同 IP、异常转移行为触发贡献衰减。
- 充值、月卡、VIP 和抽取产物不能直接提高全服贡献倍率。

九塔战流程：

| 阶段 | 内容 | 结算重点 |
| --- | --- | --- |
| 准备 | 捐献材料、布置阵眼、污染地脉、收集情报 | 开战增益、消耗折算 |
| 争夺 | 仙盟镇封修塔，魔宗污染破塔，散修完成雇佣任务 | 阵营贡献、塔状态变化 |
| 塔灵战 | 公共 Boss 或塔灵机制战 | 伤害、承伤、治疗、机制处理 |
| 结算 | 锁定每日或每周状态 | 个人奖励、阵营奖励、州状态变化 |

公共事件形态：

- 普通探索：异步自动战斗，产出灵石、基础材料、普通丹药和器胚。
- 州内秘境：小队或异步副本，产出丹方、炼器材料、九塔材料和稀有词条材料。
- 魔潮事件：按州状态触发，所有玩家可按境界分层参战。
- 世界 Boss：按伤害、承伤、治疗、机制处理、阵营任务综合计算贡献，并提供参与保底。
- 最终魔王战：根据九塔历史生成裂封魔王、九渊魔主或双相魔王形态。

各塔机制差异：

| 州域 | 塔战重点 | 低等级参与方式 | 高等级长期目标 |
| --- | --- | --- | --- |
| 冀州 | 教学镇封、基础裂隙 | 补给、清理低阶魔物 | 稳定新手州灵脉，降低新手魔潮压力 |
| 兖州 | 宗门协作、礼法阵眼 | 宗门任务、阵砂捐献 | 提升宗门建设效率和宗门战准备 |
| 青州 | 潮汐阶段、丹火争夺 | 采集潮汐草、护送丹师 | 控制丹火材料和潮汐 Boss 周期 |
| 徐州 | 驻守对抗、资源点争夺 | 战备运输、清理战场残魂 | 提高资源点收益权和 PVP 阵线优势 |
| 扬州 | 商路稳定、交易税波动 | 商队护送、灵田修复 | 维持商路繁荣，降低交易税和材料成本 |
| 荆州 | 秘境层数、灵植污染 | 采药、净化低阶妖藤 | 推进高阶秘境和内天地材料产出 |
| 豫州 | 阵营平衡、九州中枢 | 阵眼修复、声望任务 | 控制阵营补偿和主线分支权重 |
| 梁州 | 地脉修复、承伤机制 | 采矿、修复地脉节点 | 提升炼体材料、防御法宝和镇塔承伤收益 |
| 雍州 | 圣遗封印、终局前置 | 收集圣遗残页、守护遗迹 | 决定终局封印材料和魔王前置形态 |

失败代价应控制在长期可接受范围内：消耗行动次数、法宝耐久、补给或少量资源，不掉级，不摧毁核心法宝，不清空玩家长期养成。

## 十一、异步活动与主线推进

所有公共事件优先采用“随时可玩、异步推进、周期结算”。活动可以有日结、周结和赛季结算，但结算不要求玩家在线，也不让错过结算时间的玩家损失已提交贡献。

异步活动规则：

| 活动 | 参与方式 | 结算方式 |
| --- | --- | --- |
| 九塔战 | 消耗行动次数提交镇封、破封、驻守、补给 | 日结锁小状态，周结锁阶段状态 |
| 资源点 | 进攻队列、防守镜像、驻守派遣 | 按周期结算收益权 |
| 魔潮 | 全天清剿分层魔物、提交防线贡献 | 按全服清剿进度触发奖励 |
| 宗门战 | 宗门成员提交进攻、防守、战备行动 | 周期结算宗门积分和驻地收益 |
| 世界 Boss | 随时挑战镜像 Boss，伤害汇总到阶段血量池 | 阶段击破后发放排行和参与奖励 |
| 最终魔王战 | 分阶段提交战斗、封印、破封和机制贡献 | 阶段推进，不要求固定时间在线 |

主线推进规则：

- 主线按全服累计贡献、章节推荐完成日、章节保底推进日共同推进。
- 玩家错过某一天活动，不影响后续主线参与资格。
- 低活跃服务器由 NPC 兜底推进基础进度，保证纪元不会卡死。
- NPC 兜底只推进最低主线，不提供高额排行奖励，避免削弱玩家贡献价值。
- 多日未上线玩家可通过储存行动次数追回部分活动参与，但不能追回排行榜冲刺收益。

行动次数与储存：

- 九塔、资源点、PVP、魔潮等玩法使用独立行动次数或行动令。
- 未使用行动次数可储存到上限，建议基础储存 3 天，月卡或活动可提高储存上限。
- 行动次数储存只解决错过时间的问题，不提高单位行动收益。

## 十二、宗门与强 PVP

宗门是玩家长期组织，开放于筑基 / 筑身阶段。宗门承担社交、资源组织、九塔集结和强 PVP 调度职责，不能只做签到型功能。

宗门组织规则：

- 创建宗门需要灵石、宗门令和基础活跃门槛。
- 初始人数上限 20，随宗门等级提升到 50。
- 宗门可选择仙盟、魔宗或散修立场；宗门战和九塔集结按宗门立场计入阵营。
- 宗门立场切换需要宗主发起、长老确认，并有 14 天冷却。
- 退宗、踢人、转宗设置冷却，避免活动前反复跳宗套利。

宗门核心功能：

| 功能 | 玩法定位 | 约束 |
| --- | --- | --- |
| 宗门任务 | 日常协作、成员活跃 | 核心收益纳入每日 30 分钟闭环 |
| 宗门建设 | 解锁驻地、仓库、科技 | 主要消耗非绑定材料和宗门贡献 |
| 宗门科技 | 提高团队效率 | 提供便利和团队收益，不提供过高个人战力 |
| 宗门仓库 | 成员间材料互助 | 只允许非绑定材料流转 |
| 宗门驻地 | 防守、集结、资源生产 | 可被争夺影响收益，不被永久摧毁 |
| 宗门战 | 资源点、州控制度争夺 | 强 PVP 主场之一 |
| 九塔集结 | 组织塔战、魔潮、世界 Boss | 影响阵营贡献和宗门排行 |

宗门职位包括宗主、长老、执事、弟子。职位只影响管理、宣战、仓库权限、集结标记和公告调度，不直接提供高额个人战力。

| 职位 | 主要权限 |
| --- | --- |
| 宗主 | 宗门设置、宣战、立场切换、任免、仓库高级权限 |
| 长老 | 集结、宣战确认、仓库审批、成员管理 |
| 执事 | 日常任务发布、低阶仓库审批、驻守调度 |
| 弟子 | 完成宗门任务、参与集结、申请仓库物资 |

宗门仓库规则：

- 只允许非绑定基础材料、普通器胚、普通丹药和部分九塔材料流通。
- 付费产物、月卡产物、VIP 产物、限定本命法宝、古宝、绑定仙玉产物不可进入宗门仓库。
- 仓库提取设置每日额度、职位权限、物品白名单和日志记录，防止搬空仓库和小号套利。

强 PVP 采用“战场强对抗”，不采用全地图无保护乱杀。玩家可以围绕资源、宗门、九塔和州控制度激烈对抗，但失败不能造成不可逆毁号体验。

强 PVP 的异步形态为“进攻队列 + 防守镜像 + 战报复仇 + 周期结算”。玩家可设置防守阵容、法宝、技能优先级；离线时由系统按配置自动战斗。

| PVP 场景 | 开放范围 | 失败代价 |
| --- | --- | --- |
| 裂隙战场 | 阵营与散修均可参与 | 行动次数、战场积分、补给损耗 |
| 资源点争夺 | 宗门和阵营争夺 | 临时收益权、耐久、驻守状态 |
| 宗门战 | 宗门宣战或赛程匹配 | 驻地收益、宗门积分、战备物资 |
| 九塔异步争夺 | 行动令、驻守队列和周期结算 | 阵营贡献、塔状态推进权 |
| 魔潮前线 | 公共事件期间 | 排名、补给、临时战场增益 |

PVP 保护与收益衰减：

- 主城、新手州核心区域、新账号 7 日保护期禁止高阶直接击杀。
- 每日提供 PVP 行动令，未使用行动令可储存到上限，避免玩家每天必须上线。
- 高境界攻击低境界可以获胜，但贡献和掉落收益大幅衰减，防止刷小号。
- PVP 失败不掉级、不爆付费道具、不摧毁核心法宝、不清空洞府和宗门驻地。
- 强者可以影响资源点、州控制度和阵营局势，但不能靠单人战力直接决定最终九塔状态。

## 十三、核心系统

- 修炼系统：挂机获得灵力或气血精元，用于升级和突破。
- 异步活动系统：公共事件全天提交行动，日结和周结自动结算。
- 任务与活动系统：日常、周常、章节、九州事件、节日、回归和补偿活动均支持异步完成。
- 战斗系统：默认自动战斗，关键玩法可手动释放技能。
- 择日系统：每日生成天象，影响突破、炼丹、炼器、修塔、破塔收益。
- 洞府系统：建设灵田、聚灵阵、丹炉、炼器室、阵眼。
- 宗门系统：宗门建设、宗门科技、宗门仓库、宗门战和九塔集结。
- 法宝系统：普通法宝通过游戏获得，限定本命法宝和古宝通过抽取获得。
- 九塔系统：每座塔有完整度、裂隙压力、魔染度、镇封度、破封度。
- 内天地系统：化神后开启，培养生灵、派驻九州、参与世界攻略。
- 阵营系统：仙盟、魔宗、散修盟围绕九塔展开长期争夺。
- 强 PVP 系统：围绕裂隙战场、资源点、宗门战和九塔异步争夺展开。
- 排行、成就与称号系统：提供荣誉、收藏、纪元记录和轻量继承，不发放唯一战力道具。
- 文字外观与展示系统：提供称号样式、名片、战报、聊天、洞府、宗门和纪元史册展示，不提供战力。
- 最终战系统：根据纪元历史生成魔王形态与战场规则。
- 纪元结算系统：继承称号、收藏、轻量 Buff 和账户级付费货币。
- 配置与运营支撑：核心数值、奖励、概率、任务、活动、排行、公告和补偿均配置化并可追溯版本。
- UI 信息架构：第一屏进入九州地图和今日任务，不做营销页，保证玩家知道当前可做事项。
- MVP 范围控制：首版以 30-45 天小纪元验证冀、兖、青、徐四州和核心循环，后期州域与终局内容分阶段开放。
- 数值模拟系统：用玩家画像、服务器规模和抽取期望模拟一年纪元、经济产销、付费差距和九塔推进。
- PVP 匹配与防骚扰：强 PVP 只发生在明确战场，使用匹配、冷却、收益衰减和新手保护控制挫败感。
- 服务器生命周期：覆盖开服、老服新玩家、低活跃服、合服、纪元末结算和新纪元节流。
- 章节剧本系统：每章配置 NPC、州域、封印塔、事件、分支和结算文本。
- 研发 Backlog：把 GDD 拆为 P0/P1/P2 模块、接口、配置和测试任务。
- API 契约：登录、角色、行动、战斗、任务、宗门、PVP、抽卡、月卡、邮件等接口有统一请求、响应、幂等和错误码约定。
- 数据库表结构：玩家、货币、背包、行动、战斗、九州、宗门、PVP、抽卡、订单、排行、邮件、GM 日志具备主键、索引和唯一键设计。
- 配置样例：境界、道具、丹药、技能、怪物、行动、奖励、任务、卡池、月卡和 VIP 有 MVP 样例表。
- QA 测试计划：覆盖新手闭环、异步活动、PVP 防骚扰、抽卡保底、鱼排订单、经济风控和配置回放。
- GM 后台 PRD：覆盖玩家查询、订单补单、补偿、公告、配置发布、封禁风控和审计日志。
- 鱼排接入设计：预留 OAuth、积分扣减、订单回调、VIP 查询、对账和补单流程。
- 付费毕业模型：单个重度付费用户在一个纪元内可消费 10 万到 50 万鱼排积分完成构筑、古宝、外观和收藏毕业，但不购买全服胜负。
- 技术实现方案：独立 Web 优先，Web/H5 共享前端核心，鱼排聊天室右侧插件默认展示小状态卡片，点击后展开复杂功能窗口，承载修行、任务、洞府、九州、九塔、简化战报、古宝和宗门提醒等高频轻操作；后端采用全栈 TypeScript、PostgreSQL、Redis 和异步 Worker。

择日、洞府、宗门都应服务“随时玩”的核心目标：天象全天有效，洞府基础收菜控制在 5 分钟内，宗门任务和宗门战全部支持异步提交。

任务活动、排行称号、配置表、UI 信息架构和运营文案分别在独立专项文档中维护。主 GDD 只保留系统定位和边界，避免规则散落后难以验收。

MVP、数值模拟、PVP 匹配、服务器生命周期、章节剧本和研发 Backlog 是从设计进入研发排期前的补充文档，用于约束首版范围、风险验证和任务拆分。

接口契约、数据库表结构、配置样例、QA 测试计划、GM 后台 PRD 和鱼排接入设计是从研发排期进入实现前的落地文档，用于减少前后端联调、数据建模、测试验收和运营接入的不确定性。

付费毕业模型用于给重度用户提供长期消费深度。这里的“毕业”指当纪元收集、构筑和外观毕业，不是主线通关毕业，也不是 PVP 或九塔胜负毕业。

三端技术实现遵循“完整体验在 Web/H5，鱼排插件默认小卡片、点击展开复杂窗口”的原则。插件默认态只展示当前状态和少量快捷功能，展开态覆盖日常 60%-70% 的高频轻操作，但不承担完整大地图、复杂战斗回放、深层宗门管理、交易行深页、订单和服务端结算功能，所有结算都由后端 API 完成。

## 十四、战斗系统

战斗参考“一念逍遥”的自动战斗和技能释放节奏，但大幅简化技能数量、养成维度和操作负担。默认自动战斗，玩家可在关键玩法中手动释放技能。

战斗模式：

| 模式 | 适用玩法 | 操作要求 |
| --- | --- | --- |
| 全自动 | 普通探索、低阶日常、离线战斗 | 系统按技能优先级释放 |
| 半自动 | 秘境、世界 Boss、九塔战 | 自动普攻和循环技能，玩家手动释放关键技能 |
| 手动关键技 | PVP、宗门战、最终魔王战 | 玩家决定爆发、防御、控制和法宝技能时机 |

底层判定：

- 战斗采用简化回合 / 读条制，速度决定出手顺序和部分技能循环。
- 技能按冷却、优先级、目标条件自动释放，玩家可在在线挑战中手动释放关键技能。
- 默认目标选择为优先攻击当前威胁最高目标；PVP 可配置优先攻击低血量、输出位、治疗位或随机目标。
- 每场战斗设置最大回合或最大时长，超时按剩余生命、总伤害、承伤、治疗和机制贡献判定。
- 战斗日志必须记录技能释放、伤害、治疗、承伤、控制、法宝触发、异常状态和胜负原因。

玩家可配置 3 个主动技能、1 个本命法宝技能和若干被动词条。技能数量保持克制，重点体现路线差异：

| 路线 | 技能倾向 | 战斗特色 |
| --- | --- | --- |
| 练气 | 术法、控制、封印、爆发 | 技能节奏强，适合封塔和远程输出 |
| 炼体 | 承伤、反击、爆发、免控 | 生存强，适合镇塔承伤和前线 PVP |
| 成仙 | 净化、护盾、回复、守塔 | 团队保护和封印效率更强 |
| 成魔 | 污染、吞噬、斩杀、压制 | 破封、魔潮和持续侵蚀更强 |

核心战斗属性：

| 属性 | 作用 |
| --- | --- |
| 攻击 | 决定基础伤害 |
| 生命 | 决定承伤上限 |
| 防御 | 降低受到的直接伤害 |
| 速度 | 影响先手、技能循环和部分 PVP 判定 |
| 暴击 / 抗暴 | 提高或抵消爆发波动 |
| 灵力 / 气血 | 练气和炼体的路线资源 |
| 法宝强度 | 影响本命法宝和古宝技能 |
| 魔染抗性 | 降低魔染、污染和九渊类效果 |

手动释放技能只提高上限，不制造碾压。自动战斗必须能完成普通探索、核心日常和低阶秘境；手操主要在 Boss 机制、宗门战、PVP 和最终战中体现 10%-20% 的策略收益。

## 十五、成长曲线

整体成长原则为前期轻松、后期长期经营。前期让玩家快速理解修炼、突破、丹药和装备循环；中期靠丹药、法宝、阵营事件拉开流派；后期让成长从纯等级转向法则、词条、内天地、仙魔路线和全服贡献。

- 总等级按现有等级体系计算，共 9 个大境界、27 个小境界、192 个小等级。
- 小等级升级 100% 成功，只消耗修为；大境界突破改为“劫关挑战”。
- 劫关挑战失败不掉级，但获得“劫气保底”，下次突破成功率提高。
- 个人等级进度应略快于全服章节进度：活跃玩家在章节推荐完成日前 60%-75% 时间达到该章等级门槛，剩余时间用于法宝、丹药、九塔和阵营内容。
- 成长公式使用配置驱动：每个大境界有目标天数、每个小等级有权重，服务器根据目标天数和平均日修为产出反推升级需求，避免写死数值后失控。
- 每日成长来源拆成三类：稳定挂机收益占 60%-70%，主动玩法收益占 20%-30%，丹药、择日、活动占 10%-20%。

## 十六、每日玩法节奏

核心收益目标控制在每日 15-30 分钟内完成。额外深度玩法可以拉开肝度差距，但不能成为基础进度硬门槛。

| 时间 | 行为 | 目标 |
| ---: | --- | --- |
| 5 分钟 | 领取挂机、修炼、洞府、派遣、灵田 | 完成基础收菜和资源循环 |
| 10 分钟 | 普通探索、日常战斗、炼丹、炼器、宗门任务 | 完成每日核心成长 |
| 10-15 分钟 | 九塔战、PVP、秘境、魔潮或世界 Boss | 参与全服事件和社交竞争 |

深度玩家可额外投入时间刷秘境、炼器词条、资源点驻守、宗门协作和交易行经营。重肝收益主要体现为材料、词条、宗门贡献和阵营贡献，不直接绕过等级曲线。

所有日常核心收益都应允许异步完成。多日未上线玩家可使用储存行动次数追回基础参与，但排行榜、首杀、阶段冲刺等竞争收益不补发。

## 十八、丹药体系

丹药分“丹阶”和“品质”两层。丹阶对应大境界，从一阶到九阶；品质分下品、中品、上品、极品、无瑕，效果倍率分别为 0.8、1.0、1.2、1.5、2.0。

炼丹结果由主药、辅药、丹炉等级、丹火、天象共同决定：

- 主药决定丹药主类型。
- 辅药决定副效果或副作用。
- 丹炉等级决定可炼最高丹阶。
- 丹火影响成功率和品质区间。
- 天象影响成功率、品质上限和特殊产物概率。

| 丹药 | 作用 | 路线倾向 |
| --- | --- | --- |
| 聚灵丹 / 沸血丹 | 练气获得灵力，炼体获得气血精元 | 通用成长 |
| 固元丹 / 金身丹 | 提升生命、防御、抗性 | 防御生存 |
| 天元丹 / 破岳丹 | 提升攻击、术法或肉身伤害 | 输出成长 |
| 悟道丹 | 提升法则领悟、炼器悟性、词条经验 | 中后期养成 |
| 破境丹 | 提高大境界突破成功率，并增加劫气保底 | 突破辅助 |
| 清心丹 / 镇魔丹 | 降低魔染，提高镇封稳定性 | 成仙路线 |
| 九渊丹 / 血煞丹 | 提高破封、吞噬、魔染收益 | 成魔路线 |
| 回天丹 | 公共 Boss 和九塔战中的战斗消耗品 | 团队战斗 |

服用与失败规则：

- 同类同阶丹药有递减：前 3 颗 100% 效果，第 4-10 颗 50% 效果，第 11 颗后 10% 效果。
- 高一阶丹药重置该阶递减，不影响低阶记录。
- 普通炼丹失败损失材料；高品质冲刺失败返还少量丹渣。
- 丹渣可兑换低阶辅药，避免长期投入完全清空。
- 自动炼丹只允许选择“目标丹药、最高丹阶、保留材料数量”，不能自动消耗限定材料或终局材料。

## 十九、炼器与词条体系

炼器对象分为普通法宝、本命法宝和古器材料。

- 普通法宝通过游戏掉落和炼器获得，覆盖主线通关需求。
- 本命法宝可长期培养，决定流派核心。
- 古器材料包括古器胚、古器铭文和隐藏词条材料，用于高阶炼器追求。
- 九大古宝不参与炼制，只参与专属池抽取、升星和古宝日课。
- 限定法宝和九大古宝可以提供特殊机制，但不得成为主线硬门槛。

每件可炼器装备包含 1 个主词条、2-5 个副词条、0-1 个隐藏词条。

| 稀有度 | 副词条上限 | 隐藏词条 |
| --- | ---: | --- |
| 灵品 | 2 | 无 |
| 玄品 / 地品 | 3 | 无 |
| 天品 / 仙品 | 4 | 特定材料低概率出现 |
| 古器材料打造的仙品法宝 | 4 | 可出现，来源为古器铭文或隐藏词条材料 |

词条池：

| 词条类型 | 示例 |
| --- | --- |
| 通用 | 攻击、生命、防御、修炼速度、离线上限、资源掉落 |
| 练气 | 灵力上限、法则领悟、术法伤害、封印效率 |
| 炼体 | 气血上限、格挡、反伤、抗魔染、镇塔承伤 |
| 仙道 | 镇封度、净化效率、民望收益、守塔增益 |
| 魔道 | 破封度、魔染收益、吞噬效率、魔潮增益 |
| 生产 | 炼丹成功率、炼器成功率、灵田成长、洞府产出 |

炼器流程：

- 炼制：消耗器胚和材料，生成品阶、主词条和初始副词条。
- 淬炼：重随机副词条，不改变主词条。
- 铭刻：锁定 1 条词条，淬炼时不变。
- 升星：消耗器魂或重复法宝，提高基础数值。
- 洗髓：高阶玩法，允许替换主词条，但消耗稀有材料。

炼器保底使用“炉运”。连续未出稀有词条会累积炉运，炉运只提高词条稀有度，不指定具体词条。

## 二十、经济循环与交易行

经济设计目标是让材料、灵石和装备长期有产销关系，同时隔离付费产物，避免充值、月卡或 VIP 直接影响全服胜负。

资源产出来源：

| 来源 | 主要产物 | 备注 |
| --- | --- | --- |
| 挂机修行 | 修为、气血精元、灵石 | 稳定基础收益 |
| 九州探索 | 灵草、矿材、兽材、普通丹药 | 按州状态和境界修正 |
| 资源点 | 灵脉收益、地脉石、阵砂 | 受阵营控制度影响 |
| 州内秘境 | 丹方、器胚、稀有材料 | 章节逐步开放 |
| 九塔贡献 | 镇塔符、九渊残晶、功德、魔印 | 受塔状态和阵营结算影响 |
| 世界 Boss | 九塔材料、器魂、排行奖励 | 提供参与保底 |
| 章节事件 | 限时材料、纪元积分 | 推动服务器主线 |

产出原则：

- 挂机与日常提供基础产出，保障玩家稳定成长。
- 秘境和九塔提供中高阶材料，形成玩家主动参与目标。
- PVP 主要转移资源点收益权、驻守状态和积分，不凭空制造大量新资源。
- 公共事件奖励包含参与保底和排行奖励，避免低战力玩家无收益。

资源消耗来源：

| 消耗口 | 消耗内容 | 设计目的 |
| --- | --- | --- |
| 洞府升级 | 灵石、灵木、阵砂、地脉石 | 长期基础建设 |
| 炼丹 | 主药、辅药、丹火、灵石 | 消耗材料并产出成长道具 |
| 炼器淬炼 | 器胚、矿材、器魂、灵石 | 消耗装备和材料库存 |
| 铭刻 / 洗髓 | 稀有材料、器魂、仙石 | 后期词条追求 |
| 修塔 / 破塔捐献 | 九塔材料、仙魔材料 | 全服事件资源回收 |
| 装备维修 | 灵石、矿材 | 控制高频战斗产出 |
| 交易税 | 灵石或成交货币 | 抑制通胀和倒卖 |

交易行规则：

- 只允许非绑定基础材料、普通丹药、普通器胚和普通法宝流通。
- 高阶丹药、限定本命法宝、古宝、活动奖励、充值产物、月卡产物、VIP 产物、绑定仙玉产物不可交易。
- 交易税为动态 5%-15%，按服务器经济状态配置；通胀过高时自动上调。
- 高频倒卖、异常低价、异常高价、同设备互倒等行为进入风控，触发手续费提高、成交冷却或收益衰减。
- 装备可分解为器魂和部分材料；丹药失败产出丹渣，丹渣可兑换低阶辅药。
- 纪元末部分非付费资源可折算为纪元积分，限定付费货币按账户级继承规则处理。

灵石主要消耗占比建议：

| 消耗口 | 建议占比 |
| --- | ---: |
| 洞府升级 | 35%-40% |
| 炼丹 | 15%-20% |
| 炼器 | 20%-25% |
| 宗门 / 九塔捐献 | 10%-15% |
| 交易税和维修 | 5%-10% |

经济监控指标：

- 日均灵石产出、日均灵石消耗、全服灵石存量。
- 交易行成交价、成交量、撤单率和异常价格区间。
- 核心材料库存、九塔材料库存、器魂和丹渣沉淀。
- 付费货币沉淀、绑定仙玉消耗、抽取券留存。

## 二十一、纪元结算与继承

一个服务器纪元约 1 年。最终魔王战结束后进入纪元结算期，结算个人、宗门、阵营和九州世界状态，并开启下一纪元。

纪元结算内容：

| 结算项 | 说明 | 继承方式 |
| --- | --- | --- |
| 个人排行 | 等级、战力、九塔、PVP、生产等排行 | 称号、头像框、纪念记录 |
| 宗门排行 | 宗门战、九塔集结、建设贡献 | 宗门荣誉、纪念称号 |
| 阵营结局 | 仙盟、魔宗、散修盟影响力 | 服务器剧情分支记录 |
| 九州状态 | 九塔封破、魔染、灵脉、民望 | 写入纪元史册 |
| 魔王形态 | 裂封魔王、九渊魔主、双相魔王 | 解锁图鉴和外观纪念 |

下纪元可继承内容：

- 称号、外观、图鉴、纪元纪念物和少量纪元积分。
- “纪元祝福 Buff”：按上纪元表现提供轻量增益，例如修为获取 +1%-3%、离线收益 +1 小时、宗门贡献 +3%、九塔材料掉落 +2%。
- 纪元 Buff 不滚雪球，多纪元只保留最高档，溢出的历史荣誉转化为收藏、称号或纪念外观。
- 限定法宝、古宝、本命法宝不继承战力，只继承图鉴、外观和纪念标记。
- 灵石、仙石、普通材料、装备词条、宗门仓库资源不作为战力继承进入新纪元。

付费货币跨纪元继承：

| 类型 | 继承规则 |
| --- | --- |
| 付费仙玉余额 | 100% 继承到账户维度 |
| 月卡剩余天数 | 100% 顺延到新纪元 |
| 绑定仙玉余额 | 50% 继承，向下取整 |
| 付费抽卡保底进度 | 100% 继承到同类型卡池 |
| 免费券 / 活动券 / 限时券 | 不直接继承，可按规则折算为纪元积分 |
| 已抽限定法宝 / 古宝战力 | 不继承 |
| 已抽限定法宝 / 古宝图鉴 | 继承 |

付费货币继承保护玩家资产感，但不等于战力继承。不能把旧纪元付费法宝强度、词条、升星和资源库存带入新纪元。

## 二十二、货币与付费

| 货币 | 来源 | 用途 |
| --- | --- | --- |
| 灵石 | 战斗、任务、灵脉、离线 | 洞府、炼丹、普通法宝 |
| 仙石 | 高级掉落、九州事件 | 高阶设施、后期养成 |
| 仙玉 | 鱼排积分充值兑换、月卡每日发放 | 限定本命法宝池、外观、称号、便利和收藏类商品；九大古宝直抽仅预留未开放 |
| 绑定仙玉 | 活动、鱼排 VIP 联动 | 常驻池、外观、便利功能 |

仙玉和绑定仙玉不可兑换灵石或仙石。

付费尺度：

- 氪金可购买展示外观、纪元纪念物、特殊机制和操作便利，但不直接购买全服胜负。
- 重氪玩家可以更快获得限定本命法宝、外观、便利次数和养成容错，并通过大月卡稳定推进九大古宝进度。
- 重肝玩家可以通过宗门、九塔、交易行、秘境、炼器词条追赶核心战力。
- 付费优势主要体现在构筑速度、选择空间、操作便利和收集深度，不形成无解数值墙。
- 同境界同活跃度下，付费玩家强度优势应可感知；高活跃非付费玩家仍可通过长期投入获得有效 PVP、九塔和宗门战参与价值。
- 同境界同活跃下，付费玩家 PVP 有效强度优势建议控制在 10%-15%。
- PVE 和养成效率优势可到 20%-35%，但不能绕过章节、境界和全服进度限制。
- 单个重度付费用户的纪元消费目标可设计为 10 万到 50 万鱼排积分，主要消耗在限定本命法宝、外观、称号、宗门外观和纪元收藏册；九大古宝当前通过月卡赠抽和残页合成推进，不作为仙玉直抽消耗口。
- 10 万积分应形成单流派构筑毕业感，30 万积分应形成多构筑和高收藏完成度，50 万积分应接近当纪元付费收藏毕业。

新纪元节流：

- 新纪元前 14 天只开放常驻池、外观和便利类消费。
- 限定本命法宝池、九大古宝专属池按服务器章节逐步开放。
- 提前抽到的高阶机制必须受章节同步限制，未到章节只能使用低阶形态。
- 付费货币跨纪元保护玩家资产感，但不得形成新纪元开服战力碾压。

## 二十四、抽取系统

| 卡池 | 消耗 | 产出 |
| --- | --- | --- |
| 限定本命法宝池 | 仙玉 | 限定本命法宝、碎片、器魂 |
| 九大古宝专属池 | 月卡每日赠抽或九大古宝残页合成 | 九大古宝本体 |
| 常驻机缘池 | 绑定仙玉或机缘券 | 普通法宝、材料、机缘碎片 |

抽取必须公示概率、设置保底、记录历史。重复法宝转化为器魂，用于升星或兑换碎片。九大古宝专属池每次抽取只会命中九大古宝之一，不产出普通材料、器魂、古宝碎片或低阶古宝；重复命中同名古宝后，再结算为该古宝碎片和器魂。

保底与强度边界：

- 限定本命法宝池：80 抽保底本体，160 抽定向兑换；重复转化为器魂和碎片。
- 九大古宝专属池：每抽必定命中九大古宝之一，60 抽保底未满星古宝本体，120 抽定向选择 1 件九大古宝。
- 常驻机缘池：40 抽保底高阶普通法宝或核心材料。
- 付费抽卡保底跨纪元 100% 继承到同类型卡池。
- 限定法宝和九大古宝提供机制差异，不提供主线硬门槛。
- 小月卡每日 1 次九大古宝专属池赠抽，大月卡每日 2 次九大古宝专属池赠抽；赠抽当日有效，不跨日累计，不转化为仙玉。
- 非付费玩家可通过章节事件、九塔周结、最终战贡献和纪元积分获得九大古宝残页，30 残页合成 1 次九大古宝专属池抽取。
- 付费仙玉直接抽取九大古宝为后期预留入口，当前版本不开放，不扣仙玉，不计保底，不参与付费毕业模型。
- 九大古宝采用 0-5 星，首次获得为 0 星，重复古宝转化为该古宝碎片和器魂；古宝战力、星级和碎片库存不跨纪元继承。
- 九大古宝每日主动能力最多触发 3 次，被动触发不占次数。
- 太乙丹鼎不可提炼破境丹、终局丹和阵营战略丹；关键丹药每日至多提炼 1 枚。
- PVP 中同境界战斗有效属性差距设置软上限，避免抽取产物形成无解数值墙。

## 二十六、测试场景

- 新玩家 30 分钟内应完成一次小等级升级、获得第一颗丹药、炼制第一件普通法宝。
- 自动战斗测试：普通探索和日常任务可自动完成，秘境、Boss、PVP 中手动释放关键技能有明显但不过度的收益。
- 日常节奏测试：玩家每天 30 分钟内能完成核心收益闭环。
- 异步活动测试：玩家任意时间上线，都能参与九塔、宗门战、资源点、魔潮和世界 Boss，并获得有效贡献。
- 结算离线测试：玩家错过结算时间，不损失已提交贡献，不影响后续主线参与资格。
- 主线兜底测试：低活跃服务器可通过保底推进和 NPC 兜底继续推进，不发放高额排行奖励。
- PVP 离线防守测试：离线玩家使用预设技能、法宝和防守阵容自动战斗，战报可回放。
- 宗门测试：宗门仓库不能流通付费产物、限定法宝、古宝和绑定资源。
- 宗门风控测试：仓库不能被小号、跳宗、同设备互倒套利。
- 强 PVP 测试：PVP 能影响资源点、州控制度和阵营局势，但失败不造成不可逆损失。
- 新手保护测试：新账号 7 日保护期内不会被高阶玩家直接压制到无法成长。
- 活跃玩家 7 天内应进入练气/锻体中后段，并理解丹药递减和词条淬炼。
- 非付费玩家在每章推荐时间内可达到等级门槛，但词条和丹药质量低于深度玩家。
- 新玩家 7 天内能追上当前章节基础玩法，但不能影响全服九塔胜负。
- 落后 1、2、3 章的修为追赶加成分别符合 +50%、+100%、+200%，最高不超过 +300%。
- 高低等级玩家同场九塔战都有贡献，高等级不会完全吞掉低等级奖励。
- 弱势阵营补偿能提高参与收益，但不能制造必胜局。
- 丹药递减测试：同类同阶第 1、3、4、10、11 颗效果符合 100%、50%、10% 规则。
- 炼器测试：铭刻后被锁词条在淬炼中保持不变，隐藏词条只在古宝或特定高阶材料中出现。
- 经济测试：绑定仙玉不能进入限定法宝池和九大古宝专属池，付费物品不能直接提升全服贡献倍率。
- 经济风控测试：经济监控能识别灵石通胀、材料囤积和交易行异常成交。
- 交易行测试：绑定仙玉、月卡产物、VIP 产物、限定本命法宝和古宝不能上架交易行。
- 全服进度测试：小服和大服都能按一年纪元节奏推进，九州状态不会因人数差异严重失控。
- 九州开放测试：冀、兖、青、徐、扬、荆、豫、梁、雍按章节开放，系统玩法不再把幽州作为九州之一。
- 九州资源测试：九州特色材料不重复，能分别支撑炼丹、炼器、宗门、PVP、内天地和终局循环。
- 九塔机制测试：每座塔的状态都能影响本州资源、阵营收益和最终魔王形态。
- 纪元继承测试：纪元结算后继承称号、收藏和轻量 Buff，不继承破坏平衡的战力资源。
- 付费继承测试：付费仙玉和月卡剩余天数 100% 继承，绑定仙玉 50% 继承，付费抽卡保底继承到同类型卡池。
- 付费节流测试：新纪元前 14 天付费消费不造成战力碾压，限定池按章节逐步开放。
- 抽取保底测试：抽卡保底、重复转化、跨纪元保底继承规则清晰可验证。
- 付费强度测试：重氪玩家更轻松、选择更多；重肝玩家通过玩法投入可追赶核心战力。
- 便利福利测试：免费、VIP、月卡完成同一行动时奖励、贡献和战斗结算一致，仅操作耗时不同。
- VIP 月卡边界测试：VIP3 与小月卡便利一致但不获得付费仙玉，VIP4 强于小月卡但不超过大月卡。
- 自动消耗测试：自动策略不会消耗限定法宝、古宝、付费道具和高阶终局材料。
- 九大古宝测试：九大古宝专属池抽取结果只能是九大古宝之一，小月卡每日 1 抽，大月卡每日 2 抽，VIP 不额外提供九大古宝专属池抽取次数。
- 九大古宝数值测试：月卡玩家 1 个月内不会轻易满星，非付费玩家能通过残页慢速获得专属池抽取次数。
- 古宝日课测试：每日主动古宝操作不超过 3 次，不破坏 30 分钟日常目标。
- 太乙丹鼎限制测试：不能提炼破境丹、终局丹和阵营战略丹。
- 怪物 Boss 测试：普通怪、精英怪、塔灵、世界 Boss 和最终魔王都能按境界基准生成属性与阶段机制。
- 行动奖励测试：每类行动令都有基础产出，异步公共事件具备参与保底、贡献档位、排行、尾刀、过量伤害和阶段补偿。
- 付费强度公式测试：同境界同活跃下，付费玩家 PVP 有效强度优势不超过 15%。
- 配置版本测试：行动、战斗、抽卡、交易和纪元结算记录都能追溯配置版本并支持旧战报回放。
- 新手社交测试：新手 7 天内有临时修行小队或散修导师，15 天内看到宗门候补，不固定时间在线也能完成社交引导。
- 宗门细案测试：宗门任务、宗门建设、宗门战和阵营集结均可异步完成，失败不造成不可逆损失。
- 择日天象测试：天象全天有效，月卡刷新不提高最终奖励倍率，突破加成不能叠成无条件必成。
- 洞府内天地测试：洞府基础收菜 5 分钟内完成，内天地派驻受九州状态影响但不会永久损失生灵。
- 任务活动测试：玩家通过任务面板能明确看到今日核心路径，日常、周常、章节、九州事件、节日、回归和补偿活动均可异步完成。
- 排行奖励测试：个人榜、宗门榜、阵营榜、九塔榜、PVP 榜、生产榜和纪元榜奖励不包含唯一战力道具、付费仙玉、全服贡献倍率和 PVP 伤害倍率。
- 成就称号测试：成就覆盖修行、九州、九塔、PVP、宗门、生产、收集和纪元；称号可跨纪元继承展示，但战力 Buff 不滚雪球。
- 文字外观测试：展示外观能在玩家名片、排行榜、宗门、战报、聊天、鱼排插件小卡片和纪元史册展示，但不提高攻击、防御、PVP 伤害、九塔贡献倍率和全服胜负能力。
- 配置表测试：境界、道具、丹药、炼器、怪物、技能、九塔、任务、活动、卡池、月卡、VIP、古宝、宗门、天象、洞府和排行均能通过配置发布、校验和回滚。
- UI 架构测试：第一屏展示九州地图、今日任务、一键领取、行动令和关键提醒，玩家不看说明也能进入核心玩法。
- 运营文案测试：公告、邮件、补偿、封禁告知和概率公示有统一模板，不承诺不可控收益，不暗示付费必胜。
- MVP 范围测试：首版只开放冀、兖、青、徐四州和四座塔，仍能验证修行、九塔、宗门、PVP、月卡、古宝和运营日志闭环。
- 数值模拟测试：能输出 7 天、30 天、70 天、120 天、220 天、315 天、360 天成长节点，并验证小服、标准服、大服纪元节奏。
- PVP 匹配测试：同一目标反复攻击触发收益衰减和保护，高境界攻击低境界受限制，新手保护期不被高阶直接压制。
- 脚本行为风控测试：普通脚本点击不直接封禁，但伪造批量上限、月卡托管队列、自动策略槽位和重复刷 PVP / 九塔贡献会触发拒绝、截断、衰减或延迟结算。
- 服务器生命周期测试：新纪元节流、低活跃服 NPC 兜底、合服评估、纪元末结算和付费资产继承都有规则可执行。
- 章节剧本测试：每章都有核心 NPC、州域、塔、事件、分支和结算文本，魔王形态由九塔历史决定但魔王必定出世。
- 研发拆分测试：P0/P1/P2 模块、接口、配置和测试任务能支撑 MVP 排期。
- API 契约测试：状态变更接口具备幂等键，战斗、抽卡、行动、任务、订单都返回可追溯记录 ID。
- HTTP 通讯测试：三端当前默认使用 HTTP API 查询和提交操作，WebSocket / SSE 仅作为后续提醒增强，不参与奖励、抽卡、战斗、订单和贡献结算。
- 数据库结构测试：钱、物、抽卡、订单、战斗、排行、GM 操作具备主键、索引、唯一键和审计日志。
- 配置样例测试：MVP 可用样例配置跑通新手、探索、九塔、任务、抽卡、月卡和 VIP。
- QA 计划测试：P0 用例覆盖新手 30 分钟闭环、异步活动、PVP 防骚扰、抽卡保底、付费幂等和配置回放。
- GM 后台测试：订单补单、补偿邮件、公告发布、配置发布、封禁回滚均有权限、审批和日志。
- 鱼排接入测试：积分扣减、回调幂等、月卡购买、仙玉兑换、VIP 查询和每日对账均有异常处理。
- 付费毕业测试：玩家纪元消费约 10 万、30 万、50 万积分时分别达到单流派、多构筑、收藏毕业体验，但 PVP 有效强度仍不超过 15%，全服贡献倍率仍为 0%。
- 技术实现测试：独立 Web 跑通完整 MVP，H5/PWA 复用 Web 核心流程，鱼排插件默认以小状态卡片展示当前状态，点击后可展开复杂窗口查看修行、任务、洞府、九州、九塔、简化战报、古宝和宗门提醒，并完成一键领取、预设行动提交和 Web/H5 跳转。

## 二十七、设计约束

- 一个服务器纪元约 1 年通关。
- 玩家行为影响剧情过程，但不阻止魔王出世。
- 成仙、成魔都必须是完整路线。
- 充值和月卡不能直接购买全服胜负。
- 鱼排 VIP1、VIP2 低于小月卡；VIP3 可等同小月卡便利；VIP4 可高于小月卡但不得高于大月卡。
- 低等级玩家也要能参与全服事件并获得有效奖励。
- 成长曲线采用配置驱动，不在代码中硬编码所有升级数值。
- 小等级升级取消随机失败，大境界突破保留挑战感和保底机制。
- 丹药与炼器都允许自动化，但自动化不得消耗稀有、限定、终局材料。
- 九州地图是多人同服共享世界，不是单人副本选择列表。
- 新手追赶优先服务留存和进度追赶，不服务冲榜、阵营翻盘或付费放大。
- P0 规则先保证可玩、可运营、可平衡，具体数值后续进入独立数值表细化。
- 强 PVP 采用战场强对抗，不采用全地图无保护乱杀。
- “随时玩”优先级高于固定时间集体在线仪式感。
- 活动可以有日结、周结和赛季结算，但结算不要求玩家在线。
- 强 PVP 通过异步战斗、行动令、驻守队列和收益衰减解决时间压力。
- 每日半小时是核心收益目标，额外深度玩法不能成为基础进度硬门槛。
- 付费货币跨纪元保护玩家资产感；战力型付费产物不跨纪元继承。
- 新纪元必须通过章节节流保护公平开局。
- 付费优势不能直接决定全服胜负，非付费高活跃玩家必须保留核心参与价值。
- 任务、活动、排行和主线结算均支持异步参与，不要求玩家固定时间在线。
- 排行奖励以荣誉、外观、纪念和少量非核心材料为主，不发放唯一战力道具。
- 称号跨纪元继承展示和收藏，当前纪元 Buff 不滚雪球。
- 文字游戏不使用传统角色皮肤作为正式系统名；外观、展示外观和纪元纪念物只服务展示、收藏和社交，不提供战力、奖励倍率和全服贡献倍率。
- 所有核心数值、奖励、概率、任务、活动、排行和结算规则必须配置化，并在记录中保留版本号。
- 第一屏必须直接进入可玩界面，以九州地图、今日任务和一键收菜为核心信息。
- 运营文案不得承诺不可控收益，不得暗示付费必胜。
- 首版 MVP 必须收口，不允许把九州全域、完整终局和跨纪元深继承作为首版硬门槛。
- 数值上线前必须完成成长、经济、付费差距、抽卡期望和服务器规模模拟。
- 强 PVP 必须具备匹配、冷却、复仇、收益衰减和防骚扰规则。
- MVP 不禁止普通脚本点击，不做强验证码和前端反自动化对抗；行为风控只做记录、评分、限频、收益延迟结算、异常标记和后台审核。
- 脚本点击不得突破行动令、权益档位、奖励公式、托管权限、策略槽位和贡献衰减。
- 免费账号调用月卡托管队列、伪造批量上限或伪造自动策略槽位时，服务端必须拒绝或截断到当前权益上限。
- 老服新玩家、低活跃服务器、合服和纪元末清理必须有明确运营规则。
- 剧情内容必须配置化，章节任务、州事件、公告和纪元史册可以复用文本。
- 前后端接口必须以服务端结算为准，客户端不得决定奖励、贡献、抽卡结果和战斗胜负。
- 钱、物、订单、抽卡、补偿、GM 操作必须具备幂等、防重和审计日志。
- 配置样例必须能跑通 MVP 主流程，正式数值必须通过发布校验。
- P0 测试用例未通过不得进入公开测试。
- 鱼排积分和 VIP 接入必须服务端发起、回调校验、每日对账，不凭客户端结果发放权益。
- 10 万到 50 万积分消费目标必须落在收藏、构筑选择、外观和便利深度上，不得转化为无上限战斗强度。
- 大额充值包如有额外赠送，优先赠送绑定仙玉、外观券或收藏材料，不赠送额外付费仙玉破坏抽卡成本模型。
- 三端必须共用同一套游戏 API、账号体系和服务端结算规则；客户端不得自行结算战斗、奖励、抽卡、贡献和订单。
- 当前 MVP 三端交互默认使用 HTTP API；WebSocket / SSE 只作为后续提醒和状态推送增强，不能参与核心结算。
- 鱼排插件默认必须是小状态卡片，复杂功能需要点击后在窗口或抽屉中展开；插件不能复制完整 Web 站点，不保存鱼排敏感凭证，不进行客户端战斗、抽卡、奖励、贡献和订单结算。
