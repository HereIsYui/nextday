# 《九州城池纪元》重策划案 v0.2

## 一、重策划定位

《九州城池纪元》将游戏核心从“今日修行日课 + 九塔封魔提交”调整为“九州地图 + 城池经营 + 区块购买 + 州间竞争”。

后续设计默认采用九州城池 SLG 方向。玩家不再只是按日课路线完成探索、炼丹、九塔、活动，而是在九州中选择出生地，建立自己的仙城，通过经营、修行、购地扩张、出征、结盟和防守参与一整个纪元的州势竞争。

2026-07-15 起采用“主城保底、分城可争夺”的产权规则：普通无主区块只能通过出生分配或普通灵石购买获得；玩家建立的分城被攻破后，分城与所在区块可转归进攻方。主城永不易主。关隘、州府、九塔等战略设施使用独立的周期控制权，不等同于土地所有权。

本案允许否决或降级既有系统：

- “今日修行”降级为“今日战略建议”。
- “九塔封魔”降级为州级奇观和战略目标。
- 修行、炼丹、炼器、战报、宗门、活动作为城池战争和经营的支撑系统保留。
- Web 首页第一屏必须回到九州地图、我的城池、当前行军、可扩张目标和最近战报。

## 二、核心体验

核心玩家幻想：

- 我出生在九州中的一州，有自己的仙城。
- 我能经营城池、训练道兵、修炼城主与将领。
- 我能从一块出生平原开始，逐步购买平原、沼泽、森林、山地和沙漠区块。
- 我能和同州玩家结盟，和其他州、宗门或玩家竞争版图。
- 我能看见自己的购地、建城和战略行动改变地图、资源、州势力和纪元史册。

核心动词：

| 层级 | 核心动词 | 说明 |
| --- | --- | --- |
| 开局 | 选择出生州、建立主城 | 明确地理归属和第一块地 |
| 经营 | 建造、升级、生产、征兵 | 形成稳定资源和军力来源 |
| 扩张 | 探路、清野、购买、驻守 | 以产权相邻方式扩展领地 |
| 对抗 | 行军、攻城、协防、掠夺 | 和玩家、宗门、州势力竞争 |
| 协作 | 加入宗门、集结、外交、州战 | 把个人扩张接入组织战争 |
| 结算 | 日结、周结、赛季结算 | 让版图变化有阶段目标 |

## 三、九州地图结构

世界结构从“州域列表”升级为四层地图：

1. 九州：冀、兖、青、徐、扬、荆、豫、梁、雍。
2. 郡域：每州 3-6 个郡，决定出生池、资源主题和关隘线路。
3. 地块：地图最小可交互单元，包含野地、资源点、城池、关隘、九塔、魔潮点等。
4. 节点：地块内的生产或战略设施，例如灵田、矿脉、灵脉泉、分城、州府、塔基。

地图地块类型：

| 类型 | 产权 / 控制规则 | 主要作用 |
| --- | --- | --- |
| 主城地 | 出生分配，产权不易主 | 玩家核心基地和复活点 |
| 分城地 | 玩家已购平原建设，产权不易主 | 扩展建筑、驻军、税收和前线据点 |
| 野外地 | 无主时可购买；危险地先清野 | 提供基础产出和扩张路径 |
| 灵田 | 所在区块购买后使用 | 粮草、灵草、丹药材料 |
| 矿山 | 所在区块购买后使用 | 矿材、炼器材料、城防材料 |
| 灵木林 | 所在区块购买后使用 | 建筑材料、阵法材料 |
| 灵脉泉 | 所在区块购买后使用 | 修行加成、灵石、州势力贡献 |
| 关隘 | 不出售产权，周期争夺控制权 | 行军线路、州战入口、战略阻断 |
| 州府 | 不出售产权，宗门或州盟争夺控制权 | 州内治理、税收、州战核心 |
| 九塔 | 不出售产权，按州级奇观争夺控制权 | 战略增益、魔潮压力、赛季叙事 |
| 魔潮点 | 周期事件 | 公共防守、怪物潮、地图压力 |

九州主题继续保留现有设定，但用途调整为城池和战争主题：

| 冀州 | 新手与北境边防 | 低阶灵脉、玄铁矿、塔裂野地 | 新手保护、城防教学 |
| 兖州 | 宗门与礼法 | 宗门驻地、阵砂、礼法关隘 | 宗门治理和协防 |
| 青州 | 海岱与潮汐 | 水脉、海妖、潮汐灵田 | 丹药材料和水路节点 |
| 徐州 | 古战场 | 战备矿、残魂野地、军镇 | 强 PVP 和前线争夺 |
| 扬州 | 商路与富庶 | 商路、灵田、交易城 | 税收、商路和资源流通 |
| 荆州 | 泽林与秘境 | 灵植、妖藤、秘境入口 | 稀有材料和内天地前置 |
| 豫州 | 九州中枢 | 中州阵眼、州府密集 | 州战枢纽和阵营平衡 |

## 四、玩家开局与出生州

创建角色后新增“选择出生州”步骤。

默认 MVP 只开放冀州、兖州、青州、徐州作为出生州；其他州可作为赛季中后期争夺区。

出生规则：

- 每个出生州提供若干新手郡域。
- 系统按拥挤度推荐出生点，但玩家可手动选择。
- 主城初始落在新手保护地块，不会与已有主城重叠。
- 出生州决定前期任务、初始资源倾向、附近野怪和新手宗门推荐。
- 玩家可以后续迁城或转州，但需要满足冷却、费用和州战限制。

新手保护：

- 新账号前 72 小时或主城达到指定等级前，不可被主城攻击。
- 新手可主动攻击野地、资源点和低风险镜像目标。
- 新手保护不覆盖玩家主动参与的高级战略控制权争夺；主动进入州战前线即承担前线风险。
- 保护期内可加入宗门，但不能参与高收益州府争夺结算。

## 五、城池体系

玩家至少拥有一座主城。主城是账号核心资产，不可永久易主。

城池类型：

| 类型 | 归属 | 是否可被夺取 | 作用 |
| --- | --- | --- | --- |
| 主城 | 玩家 | 不可永久夺取 | 核心建筑、仓库、征兵、修行、复活 |
| 分城 | 建设玩家 | 不可转移产权，可被围困或破坏 | 前线建筑、驻军、税收、行军跳板 |
| 宗门驻地 | 宗门 | 可被围攻，不直接清空 | 集结、仓库、外交、宗门科技 |
| 州府 | 州盟 / 宗门联盟 | 可周期争夺 | 州内治理、州战积分、地图权限 |

主城状态：

| 状态 | 触发 | 影响 | 恢复 |
| --- | --- | --- | --- |
| 正常 | 默认 | 可建造、征兵、出征 | 无 |
| 免战 | 新手、迁城、被连续攻击 | 禁止被主城攻击 | 时间结束或主动取消 |
| 城防破损 | 防守失败 | 城防和产出临时下降 | 修复、等待恢复 |
| 被围困 | 敌方围城队列成功 | 出征受限、税收下降 | 宗门救援或反击 |
| 附庸 | 周期攻城失败且无救援 | 向胜方缴纳少量税贡 | 反抗、赎回、迁城 |

主城建筑：

| 建筑 | 作用 |
| --- | --- |
| 城主府 | 解锁建筑等级、队列、分城数量 |
| 仓库 | 资源容量和被掠夺保护量 |
| 兵营 | 训练道兵、提高驻防容量 |
| 城墙 | 城防、耐久、防守阵法 |
| 聚灵阵 | 修行收益、灵气储备 |
| 丹炉 | 战略丹药和补给炼制 |
| 炼器室 | 攻城器械、防具、法宝维护 |
| 灵田 | 粮草、灵草和基础材料 |
| 商栈 | 税收、交易、运输队列 |
| 阵法台 | 防守阵法、行军加速、侦查抵抗 |

## 六、资源与军队

核心资源：

| 资源 | 用途 |
| --- | --- |
| 灵石 | 通用建设、修行、市场流通 |
| 粮草 | 征兵、行军、驻防维护 |
| 矿材 | 城墙、器械、炼器、防御建筑 |
| 灵木 | 建筑升级、阵法、商路设施 |
| 灵草 | 丹药、治疗、行军补给 |
| 道兵 | 出征、驻防、攻城、资源点守卫 |
| 战功 | PVP、州战、宗门战奖励货币 |
| 州望 | 州内贡献、州府治理和赛季排名 |

军队结构：

- 城主：玩家本体，提供主属性、技能和修行境界。
- 将领：可理解为护法、弟子或道兵统领，带队出征。
- 道兵：基础兵力，按兵种和境界分层。
- 法宝 / 阵法 / 丹药：作为队伍配置和战斗消耗品。

基础兵种：

| 兵种 | 定位 |
| --- | --- |
| 剑修队 | 均衡输出，适合清野和普通攻城 |
| 盾卫队 | 高防驻守，适合守城和关隘 |
| 符修队 | 控制和阵法破坏，适合攻城 |
| 丹修队 | 治疗和续航，适合长线驻防 |
| 兽骑队 | 快速行军，适合侦查和骚扰 |

## 七、区块产权与战略控制

区块产权流程：

1. 玩家出生时免费获得一个安全平原区块并建立主城。
2. 玩家选择与已有产权相邻的无主区块。
3. 危险区块先派队清野；清野只解除危险，不授予产权。
4. 满足同州、相邻、容量和资源条件后消耗普通灵石购买。
5. 购买事务写入唯一产权、钱包日志、审计记录和地图刷新结果。

清野资格属于完成清野的玩家，不是全服公共状态。其他玩家仍需自行清野；清野失败只生成失败战报并结束该次行军，玩家可以重新整军出发。

产权与控制规则：

| 对象 | 获得方式 | 战斗结果 |
| --- | --- | --- |
| 普通区块 | 出生分配或购买 | 不能强制易主 |
| 主城 | 出生平原建立 | 可被围困、掠夺或破坏，永不转移产权 |
| 分城 | 自有平原建设 | 城墙被攻破后，分城与所在区块可被接管 |
| 资源设施 | 购买区块后建设或启用 | 可受破坏和掠夺，不转移产权 |
| 关隘 | 州战获得周期控制权 | 只改变通行和战略控制状态 |
| 州府 | 宗门联盟周期争夺 | 只改变治理控制权和积分 |
| 九塔 | 州级奇观争夺 | 只改变奇观状态与州战略效果 |

购买限制：

- 玩家区块数量受主城等级和领地容量限制。
- R1 阶段只能购买出生州内、与已有产权相邻的无主区块。
- 战略设施区块不出售，不能通过普通购买获得。
- 购买只消耗普通灵石，不接入付费仙玉、月卡或 VIP 倍率。
- 同一区块同一纪元只能存在一条有效产权记录，并发购买只能一人成功。

## 八、PVP 与保护边界

默认 PVP 采用“产权不易主、资源与战略控制权可争夺”的边界。

不可逆损失禁止项：

- 不掉境界。
- 不永久摧毁主城。
- 不清空背包和付费资产。
- 不摧毁唯一法宝和古宝。
- 不让玩家无法继续基础成长。

允许损失项：

- 城池和资源设施在围困期间停产或降产。
- 城防耐久下降。
- 部分非保护资源被掠夺。
- 驻军损耗。
- 关隘、州府和九塔的周期控制权变化。
- 附庸期少量税贡。

防骚扰规则：

- 同目标连续攻击触发收益衰减和保护。
- 高战力打低战力收益降低。
- 新手保护期禁止主城被攻击。
- 离线玩家使用防守镜像和城防预设。
- 被攻破后提供战报、复仇、迁城、求援和免战恢复路径。

## 九、宗门、州盟与州战

宗门从任务组织升级为联盟式组织。

宗门核心功能：

- 成员集结。
- 分城协防。
- 关隘争夺。
- 州府竞逐。
- 宗门科技。
- 战备仓库。
- 外交、盟约、宣战。

州盟是同州宗门的松散协作层，可用于州战和跨州防御。

州战周期：

| 周期 | 内容 |
| --- | --- |
| 日结 | 资源点、灵脉、关隘小结算 |
| 周结 | 州府、九塔、州势力排名 |
| 赛季结算 | 九州版图、州战冠军、宗门战功、个人战功 |

州势力积分来源：

- 城池占有率。
- 灵脉控制度。
- 关隘控制。
- 州府归属。
- 九塔控制和修复状态。
- 魔潮防守表现。
- 宗门战功和个人战功。

## 十、九塔新定位

九塔不再是每日固定主线，而是九州地图上的州级奇观。

九塔作用：

- 提供全州战略增益。
- 影响魔潮压力和州事件。
- 作为州战和宗门集结的重要争夺目标。
- 进入赛季史册，决定纪元叙事。

九塔状态：

| 状态 | 说明 |
| --- | --- |
| 稳定 | 本州获得基础增益 |
| 裂隙 | 魔潮频率上升 |
| 镇封 | 仙盟或守序宗门增益 |
| 污染 | 魔宗或侵略方增益 |
| 争夺 | 周期内可被集结争夺 |
| 沉寂 | 赛季锁定，等待下阶段 |

## 十二、Web 首页重构

桌面 Web 第一屏必须展示：

- 九州地图。
- 我的主城。
- 当前行军队列。
- 可扩张目标。
- 宗门 / 州战提醒。
- 最近战报。
- 今日战略建议。

首页不再把所有系统平铺，也不再以“今日只做这一步”的日课路线压制地图。

推荐布局：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 角色、主城等级、出生州、资源、队列 |
| 左侧 | 九州 / 郡域地图，可切州、筛选目标 |
| 中央 | 当前选中地块详情、行军、购买、驻防 |
| 右侧 | 我的城池、队列、战报、宗门提醒 |
| 底部 | 修行、城建、军队、宗门、市肆、史册等功能按钮 |

功能按钮点击后只展示对应功能，不把所有功能同时铺开。

| 驻防 | `/api/world/defend` | POST | 设置自有区块目标驻军数，调低自动返兵，`0` 为全部撤回，需幂等键 |

## 十四、数据模型占位

核心表：

| 表 | 说明 |
| --- | --- |
| `player_city` | 玩家主城、分城、状态、坐标和保护期 |

关键索引：

- 按州、郡、坐标查询地图。
- 按玩家查询主城、分城、队列和产权区块。

- 按宗门查询集结、协防和州战贡献。
- 按周期查询州势力和赛季结算。

## 十五、开发阶段

为避免和旧 P0/P1/P2/P3 编号冲突，新重构阶段使用 `R0-R6`，对应本案中的新策划 P0-P6。

| 阶段 | 目标 | 验收 |
| --- | --- | --- |
| R0 重定向设计 | 冻结旧路线扩展，完成新策划、接口、数据、UI、QA 占位 | 文档能指导工程拆分 |
| R1 九州地图 MVP | 出生州、主城创建、地图地块、基础行军、清野和购地 | 新号能在地图上出生并购买第一块资源地 |
| R2 城池经营 | 建筑、资源生产、仓库、征兵、队列 | 玩家能升级主城并训练道兵 |
| R3 对抗玩法 | 侦察、驻防、围困、掠夺、保护规则 | 战斗有损失和战略意义，但不转移产权 |
| R4 宗门与州战 | 集结、宣战、关隘、州府、州榜 | 宗门能组织攻打战略点 |
| R5 赛季结算 | 日结、周结、赛季史册、个人和宗门奖励 | 九州版图能形成周期结果 |
| R6 旧系统整合 | 修行、炼丹、炼器、九塔、活动接入城池战争 | 旧系统成为城池战略支撑 |

R1 已完成地图、出生建城、清野购买、领地产出、驻防调配、扩张推荐、Canvas 图层、九州摘要与总体验收。后续进入 R2 城池经营时继续保持区块产权只来自出生分配或普通灵石购买。

R2-01 已完成主城建筑、单升级队列、离线领地产出、仓库容量、资源溢出预警和城内建筑经营界面。

R2-02 已完成普通资源征兵、兵营容量、内置将领解锁、行军与驻防预设，以及队伍 / 守备快照接入。

R2-03 与 R2-04 已完成九大修仙境界主轴。境界现在决定主城与建筑成长上限、分城数量、道兵容量、将领和阵型解锁，以及增援、围城等高阶地图行动；悟道房直接展示当前进度、境界战力和下一境开放内容。R2 阶段至此完成，下一步进入 R3 围困、掠夺与保护规则。

## 十六、验收标准

- 新号能选择出生州并创建主城。
- 玩家第一屏能看到九州地图、我的城池、附近可购买目标和行军队列。
- 玩家能派遣队伍清理危险野地，并消耗普通灵石购买相邻区块。
- 玩家能在主城与自有区块间调配道兵，驻军提高只扣差额，降低或撤防后道兵返回主城。
- 玩家主城、分城和普通产权区块不会因战斗强制易主。
- 关隘、州府和九塔可以被宗门或州势力周期争夺控制权。
- 主城被攻破后不永久丢失，并触发保护、恢复、反击或迁城路径。
- 宗门能组织集结攻打关隘、州府或九塔。
- 州与州之间有明确积分、版图和周期结算。
- 免费玩家不会因为被攻打而无法继续成长。
- 付费、月卡、VIP 不直接提高购地折扣、州战胜负倍率或地图结算倍率。
