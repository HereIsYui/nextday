# 《择日飞升：九塔封魔》MVP 范围设计 v0.1

> 2026-07-06 归档说明：本文描述的是旧“九塔封魔 + 30 分钟日课”MVP。后续新主线改为 [《九州城池纪元》重策划案](JIUZHOU_CITY_ERA_DESIGN.md)，旧 MVP 内容仅作为可迁移素材和历史范围记录。

## 一、定位

本文用于约束首个可开发版本范围，避免系统一次性铺得过大。MVP 的目标不是做完整一年纪元，而是验证“多人同服、随时玩、30 分钟核心收益、九州九塔、修行成长、基础付费边界”这条主循环是否成立。

MVP 以 30-45 天小纪元测试服为目标，模拟完整纪元的前两章和部分第三章内容。

## 二、MVP 核心目标

| 目标 | 验证点 |
| --- | --- |
| 修行循环成立 | 玩家能挂机、升级、突破、吃丹、炼器 |
| 九州入口成立 | 玩家第一屏围绕九州地图行动 |
| 异步公共事件成立 | 九塔、魔潮、Boss 不要求固定时间在线 |
| 宗门雏形成立 | 玩家能加入宗门，完成建设和集结 |
| 强 PVP 边界成立 | 资源点争夺有对抗，但失败不毁号 |
| 付费边界成立 | 月卡、VIP、九大古宝不直接决定全服胜负 |
| 运营闭环成立 | 后台、日志、公告、补偿、配置版本可追溯 |

## 三、MVP 包含范围

| 模块 | MVP 范围 |
| --- | --- |
| 角色 | 创建角色、选择练气 / 炼体、基础属性、境界成长 |
| 等级 | 开放练气 / 锻体、筑基 / 筑身、金丹 / 血丹前段 |
| 九州 | 开放冀州、兖州、青州、徐州四州 |
| 九塔 | 开放玄铁塔、礼法塔、潮生塔、戈阳塔 |
| 修炼 | 在线 / 离线收益、小等级升级、大境界突破、追赶加成 |
| 战斗 | 自动战斗、半自动 Boss、离线镜像防守、战斗日志 |
| 技能 | 练气、炼体各 4-6 个基础技能，本命法宝技能各 1 个 |
| 丹药 | 一到三阶丹药、品质、递减、炼丹失败回收 |
| 炼器 | 普通法宝、主词条、副词条、淬炼、铭刻 |
| 洞府 | 灵田、聚灵阵、丹炉、炼器室 |
| 宗门 | 创建 / 加入、任务、建设、仓库白名单、集结 |
| PVP | 资源点、裂隙战场、异步进攻、防守镜像 |
| 任务 | 新手、日常、周常、章节任务、回归任务雏形 |
| 排行 | 个人贡献榜、宗门贡献榜、PVP 周榜、九塔周榜 |
| 抽卡 | 常驻机缘池、九大古宝专属池、保底、历史 |
| 月卡 / VIP | 模拟鱼排积分购买、月卡权益、VIP 便利分层 |
| 运营 | 公告、邮件、补偿、GM 查询、配置发布记录 |

## 四、MVP 延后范围

| 模块 | 延后原因 |
| --- | --- |
| 九州全域 | 梁州、雍州、豫州等中后期内容先不开放 |
| 完整最终魔王战 | MVP 用阶段 Boss 模拟，不做全年终局 |
| 内天地完整养成 | 化神后内容，MVP 只做入口预告 |
| 成仙 / 成魔完整路线 | MVP 可做阵营预热，不锁终局路线 |
| 九大古宝满星深养成 | MVP 只验证抽取、重复转化、基础机制 |
| 跨纪元完整继承 | MVP 只做结算预演和称号继承样例 |
| 合服 / 转服 | 先保留规则文档，不做首版功能 |
| 复杂节日活动 | 先做公告、签到、九州游历三类基础活动 |

## 五、MVP 玩家日常路径

1. 登录后进入九州地图。
2. 一键领取修炼、洞府、离线收益。
3. 查看今日任务，批量完成普通探索。
4. 炼 1 次丹药或淬炼 1 次法宝。
5. 提交九塔行动或宗门任务。
6. 自选参与资源点 PVP、秘境或 Boss 镜像。
7. 查看奖励、战报、宗门进度和次日目标。

免费玩家应在 30 分钟内完成上述核心收益；VIP 和月卡只减少重复点击。

## 六、MVP 章节节奏

| 测试天数 | 内容目标 | 验证重点 |
| ---: | --- | --- |
| 1-3 天 | 新手、冀州、玄铁塔裂 | 首体验、任务引导、自动战斗 |
| 4-10 天 | 筑基 / 筑身、洞府、炼丹 | 30 分钟日常、丹药递减 |
| 11-20 天 | 兖州、宗门、礼法塔 | 宗门协作、仓库风控 |
| 21-30 天 | 青州、徐州、秘境、资源点 | PVP、州事件、材料循环 |
| 31-45 天 | 阶段 Boss、MVP 结算 | 排行、称号、补偿、纪元预演 |

## 七、MVP 成功标准

| 维度 | 标准 |
| --- | --- |
| 留存 | 新手 30 分钟内完成核心闭环，7 日内知道宗门和九塔目标 |
| 节奏 | 活跃玩家 30 天内进入金丹 / 血丹前段，不明显卡死 |
| 异步 | 玩家任意时间上线均可参与九塔、资源点、Boss 和宗门任务 |
| PVP | PVP 有资源争夺压力，但失败不导致弃坑级损失 |
| 经济 | 灵石产销接近均衡，交易行无明显材料断供或通胀 |
| 付费 | 月卡玩家更省事，重氪有更多构筑选择，但 PVP 有效优势不超过 15% |
| 运营 | 订单、抽卡、战斗、交易、任务、排行都能查日志和配置版本 |

## 八、验收场景

- 首版开发任务能按本文拆成明确模块，不再同时开发所有后期系统。
- MVP 只开放四州四塔，但能模拟九州九塔完整规则。
- 内天地、完整仙魔终局、最终魔王战不阻塞首版上线。
- 免费玩家、月卡玩家、VIP 玩家完成同一行动时奖励一致。
- MVP 结算能产生称号、排行快照、邮件和运营复盘数据。
