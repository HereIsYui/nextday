# 《择日飞升：九塔封魔》后台、日志与风控设计 v0.1

## 一、定位

本文补全多人同服运营 P0 规则，用于处理：

- 充值和订单异常。
- 抽卡、交易、宗门仓库纠纷。
- 小号、脚本、刷 PVP、刷九塔贡献。
- GM 后台查询、补偿、封禁和回滚。

后台能力必须遵循“可查证、可审计、可回滚、最小权限”。

## 二、GM 权限分级

| 角色 | 权限 | 禁止 |
| --- | --- | --- |
| 客服 | 查询玩家、订单、邮件、基础日志 | 发放高价值道具、修改货币 |
| 运营 | 发公告、发补偿、配置活动、查看经济监控 | 直接改付费订单状态 |
| 高级运营 | 封禁、解封、回滚交易、处理宗门纠纷 | 绕过审批发放付费货币 |
| 技术管理员 | 数据修复、订单补单、紧急回滚 | 无审计操作 |

所有后台操作必须写入 GM 操作日志，记录操作者、时间、对象、原因、前后值。

## 三、订单与充值风控

后期接入鱼排积分后，订单流程必须包含：

1. 创建订单。
2. 锁定订单号和玩家账号。
3. 请求鱼排积分扣减。
4. 接收扣积分回调。
5. 幂等校验。
6. 发放仙玉、月卡或权益。
7. 写到账记录。

订单状态：

| 状态 | 说明 |
| --- | --- |
| created | 已创建，未扣积分 |
| pending | 等待鱼排回调 |
| paid | 扣积分成功，待发放 |
| delivered | 已到账 |
| failed | 失败 |
| refunded | 已退款或人工撤销 |

补单规则：

- 只能对 `paid` 但未 `delivered` 的订单补单。
- 补单必须校验鱼排订单号、玩家 ID、金额、货币类型和幂等键。
- 补单后必须写入订单日志和 GM 操作日志。

## 四、必须记录的日志

| 日志 | 必要字段 |
| --- | --- |
| 登录日志 | 玩家 ID、IP、设备、时间、登录方式 |
| 订单日志 | 订单号、鱼排订单号、金额、状态、回调内容 |
| 货币日志 | 货币类型、变化前后、来源、关联事件 |
| 抽卡日志 | 卡池、消耗、结果、保底进度、随机种子 |
| 交易日志 | 买卖双方、物品、价格、税率、成交时间 |
| 仓库日志 | 宗门 ID、操作者、物品、数量、审批人 |
| PVP 日志 | 双方快照、战斗 ID、收益、衰减原因 |
| 九塔贡献日志 | 州、塔、行为、贡献、状态变化 |
| 宗门权限日志 | 职位变化、踢人、退宗、立场切换 |
| GM 操作日志 | 操作者、权限、对象、原因、前后值 |

日志保存周期：

- 订单、货币、抽卡、GM 操作：至少 2 个纪元。
- 交易、仓库、PVP、九塔贡献：至少 180 天。
- 普通登录日志：至少 90 天。

## 五、小号与脚本识别

风险信号：

- 同设备或同 IP 大量账号集中创建。
- 多账号向同一账号转移材料或灵石。
- 多账号重复攻击同一 PVP 目标。
- 多账号在同一宗门仓库高频存取。
- 在线时长、操作间隔、战斗提交节奏高度一致。

处理策略：

| 风险等级 | 处理 |
| --- | --- |
| 低 | 标记观察，降低部分交易额度 |
| 中 | 贡献衰减、交易冷却、仓库额度降低 |
| 高 | 临时冻结交易、PVP 收益归零、人工审核 |
| 严重 | 封禁、回滚异常收益、宗门连带审查 |

风控不能直接没收付费仙玉，付费相关处理必须进入人工审核。

## 六、交易行风控

异常交易判定：

- 成交价低于 7 日均价 30% 以下。
- 成交价高于 7 日均价 300% 以上。
- 同设备或同 IP 账号互相交易。
- 新账号短时间内转出大量材料。
- 高频低买高卖且无正常玩法行为。

处理：

- 动态提高交易税。
- 延长成交到账时间。
- 限制高价值交易。
- 冻结异常物品并进入人工审核。
- 必要时回滚交易并记录原因。

## 七、宗门仓库风控

宗门仓库风险：

- 宗主或长老集中提走高价值物品。
- 小号加入宗门后短时间提取材料。
- 活动前大量跳宗领取仓库物资。
- 同设备账号在同一宗门反复存取。

规则：

- 新成员 24 小时内不能提取高价值材料。
- 退宗后 24 小时内不能加入新宗门参与仓库分配。
- 高价值材料提取需要长老或宗主审批。
- 所有仓库操作保留日志，可按物品追踪来源和去向。

## 八、PVP 与九塔刷分

PVP 刷分信号：

- 同一对玩家短时间内反复交战。
- 高境界账号持续攻击低境界账号。
- 战斗结果高度规律。
- 多账号向同一阵营或宗门输送分数。

九塔刷贡献信号：

- 多账号提交低价值重复行动。
- 同设备账号集中在同一塔刷补给。
- 异常时间段贡献暴增。

处理：

- 重复目标收益衰减。
- 同设备贡献衰减。
- 异常贡献进入延迟结算。
- 人工审核后回滚贡献和奖励。

## 九、公告、邮件与补偿

补偿类型：

| 类型 | 使用场景 |
| --- | --- |
| 全服补偿 | 停服、严重 Bug、结算异常 |
| 分组补偿 | 受影响州、宗门、阵营 |
| 个人补偿 | 订单异常、账号异常 |

补偿禁止项：

- 不直接发放限定本命法宝或古宝本体。
- 不发放全服贡献倍率。
- 不绕过卡池保底和纪元节流。
- 不补发排行榜冲刺收益，除非结算错误可明确证明。

## 十、经济监控

每日监控：

- 全服灵石产出、消耗、存量。
- 交易行成交额、税收、异常价格。
- 核心材料库存和流通速度。
- 仙玉、绑定仙玉、抽卡券沉淀。
- 九塔贡献和阵营人数差距。

预警阈值：

- 灵石存量连续 7 日增长超过 12%。
- 某材料价格 24 小时涨跌超过 50%。
- 单宗门仓库高价值提取超过全服均值 5 倍。
- 单账号 PVP 收益超过同境界均值 4 倍。

## 十一、验收场景

- 付费订单扣积分成功但未到账时，可按订单号补单。
- 玩家举报交易异常时，可查到买卖双方、价格、物品来源。
- 宗门仓库被搬空时，可追踪操作者和物品去向。
- PVP 刷分时，可回放战斗并回滚异常收益。
- GM 发放补偿时，能追踪操作者、对象、原因和前后值。
