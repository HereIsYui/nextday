# 《择日飞升：九塔封魔》P2 长线增强路线图 v1.0

## 一、定位与边界

P2 是 P0、P1 完成后的长线运营增强阶段，目标不是重做核心循环，而是在已经稳定的修行、探索、九塔、生产、阵营、排行、活动和合服 dry-run 之上，补充更强的文字叙事、跨纪元收藏、展示外观、高级社交和受限转服能力。

P2 默认遵守以下边界：

- 核心战斗、奖励、抽卡、贡献、排行和转服仍由服务端结算，客户端只提交意图和展示结果。
- P2 不新增付费战力皮肤，不提高攻击、防御、PVP 伤害、九塔贡献倍率、掉落倍率或全服胜负能力。
- 多纪元收藏以剧情回放、图鉴、纪念物、展示外观和有限幅纪元祝福为主，不允许多纪元 Buff 叠加滚雪球。
- WebSocket / SSE 仍只作为后续提醒和状态推送增强，不参与核心结算和奖励发放。
- 转服是最高风险能力，P2 只做 dry-run、影响报告、受限转服和人工确认流程，不默认开放自由转服。

## 四、重要 API / 数据 / 配置占位

P2 API 分组：

- `GET /api/story/scrolls`、`GET /api/story/scrolls/:scroll_id`：章节卷轴列表和详情。
- `GET /api/story/era-chronicle`：纪元史册和服务器历史片段。
- `GET /api/collection/summary`、`POST /api/collection/display/equip`：收藏馆和展示栏。
- `GET /api/appearance-plus/catalog`、`POST /api/appearance-plus/equip`：深度外观目录和装备。
- `GET/POST /api/mentor/*`：导师关系、师徒任务和出师记录。
- `GET/POST /api/sect/diplomacy/*`：宗门外交提案、审批和状态查询。
- `GET/POST /api/sect/hire/*`：跨宗门雇佣委托和协助记录。
- `POST /api/admin/transfer/dry-run`、`POST /api/admin/transfer/review`、`POST /api/admin/transfer/execute`：转服报告、审核和执行预留。

P2 数据模型占位：

- `story_scroll_record`：章节卷轴、解锁片段、战报引用和配置版本。
- `era_chronicle_record`：纪元史册快照、排行摘要、阵营结局和活动节点。
- `era_collection_record`：多纪元收藏、来源、展示状态和继承规则。
- `appearance_ownership_record`：外观持有、装备、限时、过期和来源审计。
- `mentor_relation_record`：师徒关系、申请、出师、解除和冷却。
- `sect_diplomacy_record`：宗门盟约、敌对、协防、公告和审批。
- `sect_hire_record`：跨宗门雇佣委托、奖励托管、完成记录和风控状态。
- `transfer_request_record`：转服申请、报告、审核、资产映射、执行预留和审计。

P2 配置类型占位：

- `story_presentation`：章节卷轴、文本片段、演出节奏和战报引用模板。
- `era_collection`：历史图鉴、纪元纪念物、重复转化和展示位置。
- `appearance_plus`：动态称号、名片、战报、洞府、宗门驻地装饰。
- `mentor_rule`：拜师条件、师徒任务、出师奖励、冷却和反刷规则。
- `sect_diplomacy`：外交状态、权限、冷却、协防和公告模板。
- `sect_hire`：雇佣类型、协助范围、奖励托管、衰减和黑名单。
- `transfer_rule`：阶段限制、资产映射、排行冷却、宗门处理和补偿建议。

## 五、风险与边界

- 剧情演出不能阻断核心玩法；文本缺失时要降级为普通摘要。
- 章节卷轴和纪元史册不能泄露他人敏感订单、后台风控、IP / UA 摘要或 GM 审计细节。
- 收藏和深度外观不能写入战力字段，不能改变战斗、掉落、贡献、排行和付费奖励公式。
- 导师、外交和雇佣不能成为材料转移、刷贡献、绕过宗门仓库白名单或转移付费资产的通道。
- 转服必须保留 dry-run 报告、人工审核、幂等、二次确认、回滚建议和完整审计日志。
- 最终战前 30 天禁止转服；转服后至少 7 天内不能参与部分排行奖励。

P2 总体验收：

- 玩家能在 P2-1 后阅读章节卷轴、关键战报和纪元史册，刷新后记录不丢失。
- 多纪元收藏能跨纪元展示，但不会叠加战力 Buff 或贡献倍率。
- 深度外观只影响资料页、排行榜、战报、聊天、洞府、宗门驻地和纪元史册展示。
- 导师、外交和雇佣都支持异步参与，不要求同时在线，不转移付费资产。
- 转服 dry-run 不修改真实数据，受限转服执行前必须人工审核和二次确认。
- 所有 P2 状态变更继续使用 `Idempotency-Key`，并写入可追溯审计日志。
