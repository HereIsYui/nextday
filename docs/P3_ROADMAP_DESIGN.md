# 《择日飞升：九塔封魔》P3 玩法深度与探索生态路线图 v1.0

> 历史说明：文字修行重构后，城池、领地、地图、行军、围城、州战、资源点与 PVP 均已退役。本文涉及这些能力的段落仅保留为历史记录，不可作为当前实现或验收依据；请以 `TEXT_CULTIVATION_DESIGN.md`、现行代码与测试为准。

## 一、阶段判断

当前 P1-9、P1-10 已完成新手体验补强与数值校准，P2-0 到 P2-5 已完成剧情、收藏、外观、社交和受限转服。因此下一阶段不再追加到 P2，而是进入 P3。

P3 定位为“玩法深度与探索生态”。它不是新增一个孤立大系统，而是把已经存在的探索、奇遇、战报、生产、技能、九塔和今日修行路线串成更像游戏的循环。

P3 的策划目标：

- 玩家每次探索能看到不同敌人、不同材料、不同选择后果。
- 探索产出自然导向炼丹、炼器、服丹、技能预设、九塔贡献和章节目标。
- 战报能解释为什么赢、为什么输、接下来该补什么。
- 今日修行不只是按钮列表，而是“先做 A、再做 B、最后做 C”的修行路线。
- 不增加付费战力，不提高奖励倍率，不破坏服务端结算和异步参与边界。

## 四、重要 API / 类型占位

P3 优先扩展现有接口的可选展示字段，不先新增大批新路径。核心结算仍由服务端完成，客户端只提交意图和展示结果。

可选字段占位：

- `BattleSummary.enemy_traits?: string[]`：敌人特性，例如高防、快攻、毒伤、护盾。
- `BattleSummary.loot_highlights?: string[]`：本场重点掉落或材料线索。
- `BattleSummary.battle_hint?: string`：玩家可读的战斗提示。
- `BattleSummary.counter_suggestions?: string[]`：根据怪物特性生成的反制建议。
- `TowerActionResponse / WorldBossChallengeResponse / PvpBattleResponse.reason_summary?: string[]`：九塔、Boss、PVP 的胜负原因或状态变化摘要。
- `TowerActionResponse / WorldBossChallengeResponse / PvpBattleResponse.counter_suggestions?: string[]`：九塔、Boss、PVP 的下一步建议。
- `TowerActionResponse / WorldBossChallengeResponse / PvpBattleResponse.battle_hint?: string`：多人玩法战报的玩家可读提示。
- `ExploreResponse.linked_event_hint?: string | null`：探索完成后生成奇遇的自然提示。
- `ProductionRecommendation.material_sources?: MaterialSourceHint[]`：材料来源提示。
- `SkillLoadoutResponse.available_skills[]`：已掌握、可学习、未解锁原因、学习消耗和克制标签。
- `SkillLoadoutResponse.preset_suggestions?: SkillPresetSuggestion[]`：按近期战报生成的自动释放顺序建议。
- `DailyRouteStep.source_detail?: string`：今日路线中每一步的推荐来源和降级说明。
- `DailyRouteStep.reason_tags?: string[]`：可领取、战报衔接、材料来源等玩家可见理由。
- `RouteStepViewState`：Web 内部展示层状态，区分完成、等待、缺条件、跳转和可执行。
- `MainActionFeedback`：Web 内部主行动反馈，统一处理中、完成、失败和下一步提示。
- `FeatureDrawerState`：Web 内部事务详情抽屉状态，记录当前功能、展开状态和返回今日路线入口。
- `PlaytestIssueRecord`：桌面试玩记录结构，用于记录步骤、卡点、期望反馈和复现条件。

P3 可新增或扩展接口：

- `GET /api/game/battles?province_id=&result=&enemy_trait=&limit=`：战报筛选和回放。
- `GET /api/production/material-sources?item_id=`：材料来源和缺口提示。
- `GET /api/production/skills/loadout`：技能学习目录、当前掌握状态、预设和战报建议。
- `POST /api/production/skills/learn`：学习技能，需幂等键。
- `GET /api/game/daily-route`：服务端生成今日路线。

## 五、配置占位

P3 新增配置类型：

- `explore_loot_pool_config`：州域普通材料池、权重、章节开放和总价值预算。
- `enemy_trait_config`：怪物特性、技能表现、克制关系和战报提示。
- `explore_event_link_rule_config`：州域、怪物、掉落、章节和奇遇联动规则。
- `material_chain_config`：材料来源、用途、缺口提示和生产推荐权重。
- `skill_learning_config`：技能学习条件、消耗、路线限制和默认预设建议。
- `battle_report_filter_config`：战报筛选字段、摘要格式和降级文案。
- `daily_route_config`：今日路线优先级、去重规则、桌面首屏展示数量和降级策略。
- `web_desktop_playtest_config`：30 / 60 / 120 分钟桌面试玩脚本、临时端口、视口和验收步骤。
- `web_copy_review_config`：玩家文案扫描关键词、替换建议和允许出现在折叠规则说明中的边界词。
- `mobile_reboot_design_config`：移动端后续独立设计的导航层级、首屏优先级和不可复用桌面布局清单。

配置边界：

- 掉落池只能配置普通修为、灵石、普通材料和任务进度，不得配置付费仙玉、九大古宝本体、限定法宝、唯一战力道具和奖励倍率。
- 怪物特性只能影响战斗表现、战报解释和推荐提示，不允许客户端决定胜负。
- 技能学习不能绕过境界、路线、章节和资源消耗限制。
- 今日路线只能排序和解释行动，不得绕过行动令、幂等、风控、月卡权益和服务端结算。

## 六、风险与边界

- P3 不能通过提高掉落倍率来制造可玩性，玩法厚度来自差异、选择、反馈和目标串联。
- 探索掉落池扩展后必须校验总价值预算，避免低阶材料通胀或中阶材料断供。
- 怪物特性不能把自动战斗变成强制手动在线；失败后应给出下一步建议。
- 技能学习入口不能变成付费战力入口；付费只能体现便利或展示，不改变核心战力边界。
- Web 今日路线不能隐藏玩家需要知道的限制原因，例如材料不足、未解锁州域、未入宗门。
- 插件仍保持小卡片和轻摘要，不承担完整 Web 的复杂操作。
- P3-6 到 P3-9 继续桌面优先，小于 1280px 的视口只做桌面端提示或移动端设计预备，不在本轮复用压缩桌面布局。
- 浏览器验收必须使用临时端口并在结束后释放，不能长期占用 3000 / 3001 / 3010。
