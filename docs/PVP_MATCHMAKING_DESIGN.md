# 《择日飞升：九塔封魔》PVP 匹配与防骚扰设计 v0.1

## 一、定位

本文补全强 PVP 的匹配、防守、收益衰减和防骚扰规则。目标是在保留资源争夺压力的同时，避免玩家被异步反复压制到无法成长。

核心原则：

- 强 PVP 发生在战场、资源点、宗门战、九塔争夺等明确场景。
- 不做全地图无保护乱杀。
- PVP 可以影响资源收益权、战场积分和州控制度，但失败不造成不可逆损失。
- 被攻击玩家必须有冷却、保护、战报和复仇渠道。

## 二、PVP 场景分层

| 场景 | 对抗强度 | 匹配方式 | 失败代价 |
| --- | --- | --- | --- |
| 裂隙战场 | 中高 | 境界分段 + 战力区间 | 战场积分、行动令 |
| 资源点争夺 | 高 | 资源点驻守队列 | 临时收益权、驻守状态 |
| 宗门战 | 高 | 宗门宣战 / 匹配 | 宗门积分、战备物资 |
| 九塔争夺 | 中高 | 阵营行动队列 | 阵营推进权、补给损耗 |
| 战报复仇 | 中 | 最近攻击者 | 复仇次数、积分 |
| 新手切磋 | 低 | 镜像练习 | 无真实损失 |

## 三、匹配规则

基础匹配因子：

- 境界。
- 有效战力。
- PVP 积分。
- 近期胜率。
- 阵营 / 宗门关系。
- 目标资源点等级。
- 最近被攻击次数。

匹配优先级：

1. 同境界或相邻小境界。
2. 有效战力差距不超过 20%。
3. PVP 积分接近。
4. 避免短时间重复匹配同一目标。
5. 若资源点争夺必须跨境界，收益按衰减规则处理。

跨境界规则：

| 攻击关系 | 是否允许 | 收益规则 |
| --- | --- | --- |
| 同境界 | 允许 | 正常收益 |
| 高 1 境界打低境界 | 允许 | 收益明显衰减 |
| 高 2 境界打低境界 | 限制 | 仅资源点特殊场景允许 |
| 高 3 境界及以上 | 禁止或 0 收益 | 防止刷小号 |
| 低境界越级挑战 | 允许 | 胜利有额外荣誉 |

## 四、进攻与防守队列

进攻规则：

- 每次进攻消耗 PVP 行动令。
- 批量进攻仍逐场生成战斗日志。
- 进攻前显示目标境界、资源点、风险提示和收益衰减。
- 进攻同一目标超过次数后，收益快速衰减。

防守规则：

- 玩家可设置防守阵容、技能优先级、本命法宝和目标策略。
- 离线时使用最后保存的防守镜像。
- 防守镜像使用快照，不读取实时最优状态。
- 防守失败不掉级、不爆道具、不摧毁法宝。

防守队列上限：

| 类型 | 上限 |
| --- | ---: |
| 单资源点驻守玩家 | 5-10 人，按资源点等级配置 |
| 单玩家同时驻守资源点 | 1-3 个，按境界和宗门科技配置 |
| 单宗门同资源点驻守占比 | 不超过资源点驻守上限 60% |
| 同账号每日主动进攻同一目标 | 3 次后收益降到 0 |

## 五、被攻击保护

被攻击冷却：

| 状态 | 保护规则 |
| --- | --- |
| 首次被击败 | 获得 30 分钟同目标保护 |
| 连续 2 次被击败 | 获得 2 小时同目标保护 |
| 连续 3 次被击败 | 当日同目标收益归零 |
| 新手保护期 | 禁止高阶直接攻击 |
| 长期低活跃 | 只允许镜像争夺，不影响基础成长 |

资源点保护：

- 被打下资源点后，玩家仍保留基础收益，不保留争夺加成。
- 同一资源点被连续攻破时进入短暂保护期，防止被单宗门反复扫空。
- 宗门可消耗战备物资为资源点增加临时防护，但不永久免战。

## 六、复仇与战报

战报必须展示：

- 攻击者、防守者、境界、有效战力。
- 技能释放、法宝触发、古宝触发。
- 收益、损失、收益衰减原因。
- 是否可复仇。

复仇规则：

| 规则 | 说明 |
| --- | --- |
| 复仇次数 | 每条战报 1 次，24 小时内有效 |
| 复仇消耗 | 消耗 PVP 行动令或复仇令 |
| 复仇收益 | 以荣誉、积分、少量资源为主 |
| 复仇保护 | 不绕过新手保护和跨境界限制 |
| 复仇失败 | 不产生额外损失 |

## 七、收益衰减

重复目标衰减：

| 当日攻击同一目标次数 | 收益 |
| ---: | ---: |
| 第 1 次 | 100% |
| 第 2 次 | 50% |
| 第 3 次 | 20% |
| 第 4 次及以后 | 0% |

弱势保护衰减：

- 高境界打低境界按 `NUMERIC_DESIGN.md` 的 PVP 收益衰减执行。
- 同设备、同 IP、异常账号组互刷时收益延迟结算。
- 战斗结果高度规律时进入人工审核。

## 八、宗门战匹配

宗门战匹配因子：

- 宗门等级。
- 近 7 日活跃人数。
- 宗门战力中位数。
- 宗门战积分。
- 近 14 日宣战次数。
- 立场和州域目标。

宗门战防套利：

- 宣战后 24 小时内加入成员不能参与本轮核心奖励。
- 退宗、转宗、立场切换有冷却。
- 宗门战奖励按个人有效贡献发放，不只按宗门胜负发放。
- 小宗门匹配大宗门时获得 NPC 防守和贡献补偿，但不直接判胜。

## 九、九塔与阵营 PVP

九塔 PVP 不直接让单个玩家决定塔状态。

- 单场 PVP 胜利只影响个人贡献、阵营贡献和局部驻守状态。
- 塔状态变化依赖全服累计行动和周期结算。
- 阵营弱势方可获得任务刷新、NPC 支援和贡献补偿。
- 付费便利、月卡、VIP 不提高九塔贡献倍率。

## 十、验收场景

- 玩家不会被同一目标无限攻击刷收益。
- 新手和低活跃玩家不会被高阶玩家压制到无法成长。
- 强 PVP 能改变资源点收益权和战场积分，但不造成不可逆损失。
- 离线防守使用预设镜像，战报可回放。
- 宗门战不能通过临时跳宗、小号输送、同设备互刷套利。
- 付费玩家在同境界 PVP 的有效优势不超过 15%。
