# 《择日飞升：九塔封魔》任务与活动设计 v0.1

> 历史说明：文字修行重构后，城池、领地、地图、行军、围城、州战、资源点与 PVP 均已退役。本文涉及这些能力的段落仅保留为历史记录，不可作为当前实现或验收依据；请以 `TEXT_CULTIVATION_DESIGN.md`、现行代码与测试为准。

## 一、定位

本文补全任务与活动系统，用于支撑玩家每天上线后明确知道“今天做什么”，并保证所有核心任务和活动都支持异步完成。

核心原则：

- 每日核心收益控制在 30 分钟内。
- 任务和活动不要求固定时间在线，玩家可随时提交行动。
- 排行冲刺奖励不补发，基础参与奖励可在异常时补偿。
- 任务奖励不突破付费强度边界，不直接发放唯一战力道具。
- 所有任务、活动和奖励必须记录配置版本，便于回放、补偿和纠纷处理。

## 二、任务类型总览

| 类型 | 刷新周期 | 主要目标 | 奖励定位 |
| --- | --- | --- | --- |
| 日常任务 | 每日 | 引导 30 分钟核心闭环 | 修为、灵石、基础材料、活跃度 |
| 周常任务 | 每周 | 引导宗门、九塔、秘境和 PVP 长线参与 | 中阶材料、宗门贡献、纪元积分 |
| 章节任务 | 随章节开放 | 推动九州主线和境界目标 | 主线材料、称号进度、剧情记录 |
| 九州事件 | 按州状态触发 | 强化共享大地图与九塔状态 | 州特色材料、阵营贡献 |
| 节日活动 | 运营配置 | 提供主题玩法和短期目标 | 外观、纪念物、非核心材料 |
| 回归活动 | 玩家触发 | 帮助流失玩家追赶 | 修为追赶包、低阶材料、行动令 |
| 补偿活动 | 异常触发 | 修复停服、Bug、结算异常影响 | 基础资源、行动令、补偿邮件 |

## 三、异步完成规则

任务和活动采用“接取 / 激活 - 提交行动 - 周期结算 - 奖励领取”的异步流程。

| 阶段 | 规则 |
| --- | --- |
| 激活 | 达到等级、章节、州域或活动条件后自动激活，不要求手动接取 |
| 提交 | 玩家随时消耗行动令或材料提交行动 |
| 进度 | 个人进度、宗门进度、阵营进度和全服进度分别记录 |
| 结算 | 日结、周结、章节结算由系统自动执行，不要求玩家在线 |
| 领取 | 已结算奖励进入奖励池或邮件，玩家下次上线可领取 |
| 补偿 | 因系统异常导致基础参与奖励缺失时可补偿，排行冲刺奖励原则上不补发 |

刷新建议：

- 日常刷新：服务器每日 05:00。
- 周常刷新：每周一 05:00。
- 章节任务：随服务器章节开放和保底推进自动刷新。
- 九州事件：按州状态、九塔状态和运营配置触发。
- 限时活动：允许展示活动期，但参与行为全天开放。

## 四、日常任务结构

日常任务只覆盖核心收益，不强迫玩家完成所有深度玩法。

| 任务组 | 示例任务 | 目标耗时 | 核心奖励 |
| --- | --- | ---: | --- |
| 修行 | 领取挂机收益、完成 1 次小周天 / 淬血 | 2-3 分钟 | 修为或气血精元 |
| 洞府 | 收取灵田、完成 1 次设施生产 | 3-5 分钟 | 灵石、灵草、设施经验 |
| 探索 | 批量完成普通探索或采集 | 5-8 分钟 | 基础材料、普通器胚 |
| 丹器 | 炼制 1 次丹药或淬炼 1 次法宝 | 3-5 分钟 | 丹药、丹渣、器魂 |
| 九州 | 提交 1-3 次九塔或州事件行动 | 5-8 分钟 | 九塔贡献、州特色材料 |
| 宗门 | 完成 1 次宗门任务或捐献 | 2-4 分钟 | 宗门贡献、宗门建设值 |
| 自选 | PVP、秘境、Boss 三选一 | 5-8 分钟 | 对应积分和参与保底 |

日常活跃奖励：

| 活跃档 | 条件 | 奖励定位 |
| --- | --- | --- |
| 20 | 完成基础收菜 | 少量修为、灵石 |
| 50 | 完成修行、洞府、探索 | 行动令、基础材料 |
| 80 | 完成九州或宗门参与 | 州特色材料、宗门贡献 |
| 100 | 完成一个自选玩法 | 少量绑定仙玉、纪元积分碎片 |

活跃奖励边界：

- 绑定仙玉只用于常驻池、外观和便利功能，不能进入限定本命法宝池和九大古宝专属池。
- 活跃奖励不得提供全服贡献倍率、PVP 伤害倍率或唯一战力道具。
- 月卡和 VIP 可减少领取与提交操作，但不提高活跃奖励数量。

## 五、周常任务结构

周常用于鼓励长期目标，允许玩家分多天完成，未要求某个固定时间上线。

| 周常 | 完成方式 | 奖励定位 |
| --- | --- | --- |
| 九州巡行 | 在 3 个已开放州完成探索或州事件 | 州特色材料包 |
| 九塔同心 | 累计提交九塔行动 15 次 | 九塔材料、阵营声望 |
| 宗门共筑 | 完成宗门任务或建设 10 次 | 宗门贡献、宗门建设材料 |
| 秘境寻珍 | 完成秘境或扫荡 8 次 | 丹方碎片、词条材料 |
| 战场砺锋 | 完成 PVP 或资源点行动 10 次 | PVP 积分、战备材料 |
| 丹器兼修 | 炼丹、炼器累计 12 次 | 丹渣、器魂、低阶辅药 |
| 镇魔纪事 | 参与魔潮、Boss 或塔灵阶段 | 纪元积分、称号进度 |

周常不要求满勤。玩家完成 70%-80% 周常即可拿到大部分基础奖励，剩余奖励偏荣誉、纪念和少量非核心材料。

## 六、章节任务

章节任务跟随服务器纪元推进，用于串联等级、九州开放和主线剧情。

| 章节 | 章节任务重点 | 异步要求 |
| --- | --- | --- |
| 第一章 塔裂冀州 | 完成修炼、探索、第一次九塔行动 | 新手可随时触发教学 |
| 第二章 筑基立命 | 加入或预备加入宗门，参与兖州建设 | 不要求同时在线集结 |
| 第三章 金丹问道 | 青州秘境、徐州资源点、阵营预热 | 可用镜像战斗和行动令推进 |
| 第四章 元婴分神 | 扬州交易、荆州秘境、蜀道圣遗卷 | 阶段道具可通过周常补齐 |
| 第五章 化神开界 | 选择成仙、成魔或散修，开启豫州中枢 | 阵营选择有确认和冷却 |
| 第六章 炼虚窥真 | 梁州、雍州开放，多塔并行 | 全服贡献和 NPC 兜底共同推进 |
| 第七章 合体定局 | 九塔状态逐步锁定 | 玩家行为影响魔王形态 |
| 第八章 大乘渡劫 | 终局材料和渡劫准备 | 错过阶段可通过保底任务补基础材料 |
| 第九章 真仙与真魔 | 最终魔王战与纪元结算 | 结算不要求在线 |

章节任务奖励以剧情记录、主线材料、称号进度和纪元积分为主，不提供不可替代战力道具。

## 七、九州事件

九州事件按州域状态和章节开放，全部支持全天提交行动。

| 州域 | 事件示例 | 主要奖励 |
| --- | --- | --- |
| 冀州 | 玄铁塔裂、北境魔潮、新手护送 | 玄铁残片、低阶灵草 |
| 兖州 | 礼法复兴、宗门议盟、阵砂急募 | 宗门令、阵砂、礼器残片 |
| 青州 | 潮生异动、海妖侵岸、丹火潮汐 | 潮汐草、海妖骨、丹火材料 |
| 徐州 | 戈阳战线、资源点争夺、战魂夜巡 | 战魂铁、血晶、战备符 |
| 扬州 | 商路护送、琉光税议、灵田复苏 | 灵木、商票、聚灵阵材 |
| 荆州 | 万木秘境、妖藤净化、灵植迁栽 | 灵植、妖藤、内天地种子 |
| 豫州 | 天衡裁断、阵营调停、中枢阵眼 | 天衡石、阵眼核心、声望材料 |

事件结算结构：

- 参与保底：至少 1 次有效行动。
- 贡献档位：按个人贡献和境界分段结算。
- 州状态变化：影响魔染、民望、灵脉和塔状态。
- 排行展示：只提供荣誉、称号进度、外观碎片和少量非核心材料。

## 八、节日活动

节日活动应优先复用已有系统，不新增复杂定时玩法。

推荐活动类型：

| 类型 | 玩法 | 奖励边界 |
| --- | --- | --- |
| 节令签到 | 活动期每日领取，可补签少量天数 | 外观碎片、绑定仙玉、行动令 |
| 九州游历 | 完成指定州事件或探索 | 特色材料、节令称号进度 |
| 丹器加试 | 炼丹、炼器获得活动积分 | 丹渣、器魂、纪念材料 |
| 魔潮共讨 | 活动期魔潮阶段血量池 | 参与保底、排行荣誉 |
| 宗门同贺 | 宗门成员共同提交材料 | 宗门装饰、宗门荣誉 |

节日活动禁止：

- 暗示付费必胜。
- 要求固定时间在线抢奖励。
- 发放唯一战力道具。
- 用活动限定材料绕过章节节流。

## 九、回归活动

回归活动用于降低流失玩家回坑门槛，不用于冲榜。

触发条件建议：

- 连续 14 天未登录。
- 当前境界低于服务器推荐境界至少 1 章。
- 账号未处于风控冻结或封禁状态。

回归任务：

| 天数 | 目标 | 奖励 |
| --- | --- | --- |
| 第 1 天 | 领取回归修为包、完成基础探索 | 修为追赶包、探索令 |
| 第 2 天 | 完成洞府和丹药任务 | 低阶材料、丹渣 |
| 第 3 天 | 参与九塔或州事件 | 九塔令、参与保底 |
| 第 4 天 | 完成秘境或 Boss 镜像 | 秘境令、器魂 |
| 第 5 天 | 加入宗门或完成散修任务 | 宗门贡献或散修声望 |
| 第 6 天 | 完成 PVP 或资源点镜像行动 | 战备材料、PVP 积分 |
| 第 7 天 | 完成回归总结任务 | 纪元积分、回归称号进度 |

回归加成只作用于个人修为、气血精元和低阶基础材料，不提高九塔贡献倍率、PVP 伤害和抽卡收益。

## 十、补偿活动

补偿按影响范围分为全服、分组和个人。

| 补偿类型 | 使用场景 | 发放方式 |
| --- | --- | --- |
| 全服补偿 | 停服、严重 Bug、全服结算异常 | 邮件发放 |
| 分组补偿 | 某州、宗门、阵营受影响 | 按影响范围发放 |
| 个人补偿 | 订单、背包、战斗异常 | 客服审核后发放 |

补偿可发：

- 行动令。
- 基础材料。
- 少量绑定仙玉。
- 非核心纪念材料。
- 因系统错误损失的等价普通资源。

补偿不可发：

- 限定本命法宝或九大古宝本体。
- 付费仙玉，除非订单核验明确成立。
- 全服贡献倍率、PVP 伤害倍率。
- 排行冲刺奖励，除非可证明结算错误。

## 十一、防刷规则

- 日常和周常奖励必须绑定有效活跃行为，不能只靠小号登录领取高价值材料。
- 同设备、同 IP、异常账号组完成同类任务时，进入风控衰减。
- 任务进度不得通过宗门仓库和交易行反复转移刷取。
- PVP、九塔、资源点任务按境界分段归一，防止高阶玩家刷低阶账号。
- 活动积分和排行分必须记录来源行动、战斗日志和奖励配置版本。

## 十二、验收场景

- 玩家上线后通过任务面板能明确看到今日核心路径。
- 免费玩家 30 分钟内可完成日常核心收益。
- 日常、周常、章节和活动任务都能异步完成，不要求固定时间在线。
- 玩家错过结算时间不损失已提交贡献。
- 排行冲刺奖励不补发，基础参与奖励可按异常范围补偿。
- 回归玩家 7 天内能恢复基础循环，但不能直接冲击榜单。
- 任务奖励不提供唯一战力道具，不提高全服贡献倍率。
- 每条任务和活动记录都能追溯配置版本、奖励版本和规则版本。
