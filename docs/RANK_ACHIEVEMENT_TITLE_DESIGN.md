# 《择日飞升：九塔封魔》排行榜、成就与称号设计 v0.1

## 一、定位

本文补全排行榜、成就和称号系统，用于支撑长期荣誉、社交展示、纪元继承和运营活动。

核心原则：

- 排行奖励以荣誉、外观、纪念和少量非核心材料为主。
- 不发放唯一战力道具，不直接决定全服胜负。
- 排行按境界、服务器章节和活动周期分段，避免头部玩家垄断全部奖励。
- 称号可以跨纪元继承，但战力 Buff 不滚雪球。
- 所有排行快照、成就达成和称号发放必须记录配置版本。

## 二、排行榜类型

| 榜单 | 统计对象 | 周期 | 奖励定位 |
| --- | --- | --- | --- |
| 个人境界榜 | 玩家等级、突破时间 | 章节 / 纪元 | 称号、头像框、纪念记录 |
| 个人战力榜 | 同境界有效战力 | 周 / 章节 | 荣誉、外观碎片、少量材料 |
| 九塔贡献榜 | 镇封、破封、补给、驻守贡献 | 日 / 周 / 章节 | 阵营声望、称号进度 |
| PVP 战场榜 | 战场积分、胜率、有效挑战 | 周 / 赛季 | 战场称号、外观碎片 |
| 宗门榜 | 建设、宗门战、九塔集结 | 周 / 章节 / 纪元 | 宗门荣誉、宗门装饰 |
| 阵营榜 | 仙盟、魔宗、散修贡献 | 周 / 章节 | 阵营称号、剧情记录 |
| 生产榜 | 炼丹、炼器、洞府、交易贡献 | 周 / 章节 | 生产称号、非核心材料 |
| 九州榜 | 州事件贡献、州控制度参与 | 周 / 章节 | 九州游历称号 |
| 纪元总榜 | 纪元综合表现 | 纪元结算 | 纪元称号、图鉴、轻量祝福 |

## 三、分段与快照

分段规则：

- 境界分段：练气 / 锻体、筑基 / 筑身、金丹 / 血丹等分段独立排行。
- 章节分段：只统计当前章节开放玩法，避免高阶跨章节碾压。
- 阵营分段：仙盟、魔宗、散修可分别展示，同时保留全服榜。
- 宗门分段：按宗门等级或活跃人数分层，避免小宗门完全失去竞争意义。

快照规则：

- 日榜用于展示和轻量奖励。
- 周榜用于主要周期奖励。
- 章节榜用于剧情节点和称号进度。
- 纪元榜用于跨纪元继承和纪元史册。
- 结算时生成不可变快照，后续补偿或回滚必须生成修正记录，不直接覆盖原始快照。

## 四、排行奖励边界

| 奖励类型 | 是否允许 | 说明 |
| --- | --- | --- |
| 称号 | 允许 | 可展示，可少量提供当纪元非核心 Buff |
| 头像框 / 展示外观 | 允许 | 可跨纪元收藏 |
| 纪念物 | 允许 | 主要用于展示和图鉴 |
| 非核心材料 | 允许 | 数量受配置限制 |
| 绑定仙玉 | 少量允许 | 不能进入限定本命法宝池和九大古宝专属池 |
| 付费仙玉 | 不允许 | 只来自鱼排积分充值和月卡 |
| 唯一战力道具 | 不允许 | 避免头部垄断 |
| 全服贡献倍率 | 不允许 | 不能直接决定九塔或最终战 |
| PVP 伤害倍率 | 不允许 | 防止强 PVP 失衡 |

排行奖励应采用“名次奖励 + 档位奖励 + 参与保底”结构。名次奖励偏荣誉，档位奖励偏材料，参与保底保障普通玩家有反馈。

排行展示外观奖励范围：

| 展示项 | 适用榜单 | 边界 |
| --- | --- | --- |
| 称号样式 | 个人境界榜、九塔榜、PVP 榜、纪元总榜 | 可展示，可跨纪元收藏，不叠加战力 Buff |
| 头像框 / 名片框 | 个人榜、生产榜、活动榜 | 只影响资料页、排行榜、聊天和插件小卡片 |
| 战报样式 | PVP 榜、九塔榜、世界 Boss 榜 | 不改变战斗日志内容和奖励结算 |
| 纪元史册外观 | 纪元总榜、最终魔王战榜 | 只影响历史纪元展示 |
| 宗门牌匾 / 宗门旗号 | 宗门榜、宗门战榜 | 不提高宗门科技、建设、九塔和 PVP 收益 |
| 图鉴外观 | 收集榜、古宝图鉴榜、法宝图鉴榜 | 只影响图鉴和名片展示 |

排行展示外观不得包含攻击、防御、生命、PVP 伤害、九塔贡献倍率、世界 Boss 贡献倍率和最终魔王贡献倍率。若称号在当前纪元有轻量效果，必须走称号规则，且同类效果只取最高。

## 五、排行防刷

风险信号：

- 同设备、同 IP 账号互刷 PVP 或九塔贡献。
- 同一宗门短时间异常集中交易、仓库流转后冲榜。
- 低等级账号向高等级账号输送材料、战场积分或贡献。
- 战斗结果、提交间隔、挑战目标高度规律。
- 结算前异常转宗、转阵营、改名规避追踪。

处理策略：

| 风险等级 | 处理 |
| --- | --- |
| 低 | 排行分延迟入榜，标记观察 |
| 中 | 异常分数临时冻结，奖励延迟发放 |
| 高 | 剔除异常分数，进入人工审核 |
| 严重 | 回滚奖励，封禁或宗门连带审查 |

排行奖励发放前应经过风控二次校验。结算后发现异常时，可回收异常奖励并发布修正公告。

## 六、成就系统

成就用于长期目标、收藏和纪元记录，不应成为每日压力。

| 成就分类 | 示例 | 奖励 |
| --- | --- | --- |
| 修行 | 首次筑基、首次化神、渡劫成功 | 称号进度、绑定材料 |
| 九州 | 首次踏入九州全域、完成州事件 | 九州纪念物 |
| 九塔 | 镇封百次、破封百次、塔灵战参与 | 九塔称号进度 |
| PVP | 首胜、连胜、逆境胜利 | 战场称号、外观碎片 |
| 宗门 | 建设贡献、宗门战参与、宗门职位 | 宗门荣誉 |
| 生产 | 炼出无瑕丹、刷出稀有词条 | 生产称号、器魂 / 丹渣 |
| 收集 | 九大古宝图鉴、法宝图鉴、怪物图鉴 | 图鉴称号、纪念外观 |
| 纪元 | 参与最终魔王战、完成纪元结算 | 纪元积分、纪元称号 |
| 社交 | 加入宗门、完成导师任务、组队秘境 | 社交称号进度 |

成就奖励边界：

- 首次成就可给明确反馈，但不可大幅提升战斗强度。
- 高难成就奖励偏称号、外观和纪念，不给唯一战力道具。
- 跨纪元成就保留达成记录和收藏，不保留破坏平衡的战力数值。

## 七、称号系统

称号由“展示文本 + 来源 + 稀有度 + 当前纪元效果 + 继承规则”组成。

| 稀有度 | 来源 | 示例 |
| --- | --- | --- |
| 凡称 | 日常、普通成就 | 初履仙途、北境巡行 |
| 灵称 | 周常、州事件 | 玄铁守灯、潮生采药客 |
| 玄称 | 九塔、PVP、宗门 | 戈阳破阵、礼法执令 |
| 地称 | 章节排行、阵营贡献 | 天衡裁断、万木听风 |
| 天称 | 纪元榜、最终战 | 九塔留名、太初镇渊 |
| 仙魔称 | 成仙 / 成魔终局 | 云阙真君、九渊魔君 |

称号效果：

- 普通称号只展示。
- 当前纪元称号可提供轻量便利或非核心收益，例如离线收益 +30 分钟、宗门贡献 +1%、低阶材料掉落 +1%。
- PVP、九塔、最终魔王战不允许因称号获得直接伤害倍率或全服贡献倍率。
- 同类称号效果只取最高，不叠加。

## 八、称号继承

跨纪元继承内容：

- 称号名称和获得记录。
- 称号外观、头像框、纪念物。
- 纪元史册中的名次和战报摘要。

不跨纪元继承内容：

- 当前纪元排行 Buff。
- 当纪元材料加成。
- 与境界、法宝、词条绑定的战力效果。

纪元祝福 Buff：

- 由纪元结算生成，不由单个称号无限叠加。
- 多纪元只保留最高档，历史祝福转化为收藏。
- 建议范围：修为获取 +1%-3%、离线收益 +1 小时、宗门贡献 +3%、九塔材料掉落 +2%。

## 十、验收场景

- 排行榜奖励不包含唯一战力道具、付费仙玉、全服贡献倍率和 PVP 伤害倍率。
- 低等级玩家在境界分段榜中有可见竞争空间。
- 宗门榜和阵营榜不因小号输送、跳宗、转阵营被轻易刷榜。
- 成就能覆盖修行、九州、九塔、PVP、宗门、生产、收集和纪元。
- 称号可跨纪元继承展示，但战力 Buff 不滚雪球。
- 纪元结算能生成排行快照、称号奖励、纪元史册和轻量祝福。
- 异常排行可追溯快照、行动记录、战斗日志和配置版本。
