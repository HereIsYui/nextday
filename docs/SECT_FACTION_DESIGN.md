# 《择日飞升：九塔封魔》宗门与阵营细案 v0.1

> 历史说明：文字修行重构后，城池、领地、地图、行军、围城、州战、资源点与 PVP 均已退役。本文涉及这些能力的段落仅保留为历史记录，不可作为当前实现或验收依据；请以 `TEXT_CULTIVATION_DESIGN.md`、现行代码与测试为准。

## 一、定位

本文补全宗门、宗门战、宗门建设和仙魔阵营协作的可开发规则。宗门是长期社交组织，阵营是服务器主线立场，二者共同服务九州、九塔、强 PVP 和纪元结算。

核心原则：

- 宗门是协作和调度中心，不是高额个人战力来源。
- 宗门玩法全部支持异步参与，不要求固定时间集体在线。
- 宗门立场影响九塔、宗门战和州控制度，但不能强迫玩家改变个人仙魔路线。
- 弱势阵营获得参与补偿，不直接获得胜利。

## 二、开放与创建

| 项目 | 规则 |
| --- | --- |
| 开放阶段 | 筑基 / 筑身 |
| 创建消耗 | 灵石、宗门令、少量阵砂 |
| 创建门槛 | 近 7 日登录 3 天，完成冀州塔战教学 |
| 初始人数 | 20 |
| 最高人数 | 50 |
| 宗门立场 | 仙盟 / 魔宗 / 散修 |

新手在第 7 天可进入宗门候补，第 15 天进入宗门推荐。候补期贡献可在正式入宗后按比例转为个人宗门贡献。

## 三、职位与权限

| 职位 | 权限 | 风控边界 |
| --- | --- | --- |
| 宗主 | 宗门设置、宣战、立场切换、任免、仓库高级审批 | 高危操作需二次确认 |
| 长老 | 战备调度、成员管理、仓库审批、集结标记 | 不能解散宗门 |
| 执事 | 发布日常目标、低阶仓库审批、驻守调度 | 不能修改立场 |
| 弟子 | 完成任务、参与集结、申请仓库物资 | 受仓库额度限制 |

权限变更必须记录日志。宗主连续 14 天未登录时，长老可发起宗主转移投票。

## 四、宗门建设

宗门建设消耗非绑定材料、宗门贡献和宗门资金，不消耗付费道具。

| 建筑 | 功能 | 产出 / 效果 | 边界 |
| --- | --- | --- | --- |
| 山门 | 宗门等级和人数上限 | 解锁成员上限和职位权限 | 不提供个人战力 |
| 藏经阁 | 宗门科技 | 便利、生产、九塔效率 | 不提高全服贡献倍率 |
| 丹房 | 炼丹协助 | 低阶辅药、丹渣兑换效率 | 不产出付费丹药 |
| 器阁 | 炼器协助 | 普通器胚、器魂回收效率 | 不产出限定法宝 |
| 阵台 | 九塔集结 | 镇封、破封、补给预设 | 只优化组织效率 |
| 仓库 | 材料互助 | 非绑定材料流转 | 禁止付费产物流通 |
| 驻地 | 宗门战防守 | 驻守队列、资源点收益 | 可降收益，不永久摧毁 |

宗门科技分为生产、战备、九塔、便利四类。科技只能提高团队效率、材料回收和组织成本，不直接提供高额个人面板。

## 五、宗门任务

宗门任务纳入每日 30 分钟核心闭环，单人异步完成后计入宗门进度。

| 任务 | 行为 | 奖励 | 说明 |
| --- | --- | --- | --- |
| 山门洒扫 | 日常提交 | 宗门贡献、低阶材料 | 新手友好 |
| 灵脉巡护 | 九州探索 | 灵木、阵砂、宗门资金 | 支撑建设 |
| 丹房协作 | 炼丹或提交丹渣 | 辅药、宗门贡献 | 生产向 |
| 器阁协作 | 分解普通法宝 | 器魂、宗门贡献 | 回收向 |
| 九塔补给 | 提交九塔行动 | 阵营贡献、宗门贡献 | 不提高个人贡献倍率 |
| 前线驻守 | 设置防守镜像 | 战备积分、宗门积分 | PVP 向 |

每日宗门任务建议 3 个核心任务 + 2 个可选任务。错过当天不影响后续主线资格。

## 六、宗门战

宗门战采用异步“进攻队列 + 防守镜像 + 战备提交 + 周期结算”。

| 阶段 | 持续 | 行为 |
| --- | --- | --- |
| 宣战 / 匹配 | 24 小时 | 系统匹配或宗门宣战 |
| 战备 | 24 小时 | 提交战备符、设置防守阵容 |
| 交锋 | 48 小时 | 消耗 PVP 行动令提交进攻 |
| 结算 | 自动 | 结算宗门积分、资源点收益和战报 |

宗门战胜负由进攻积分、防守积分、战备积分和机制任务共同决定。高战玩家效率更高，但不能单人决定全宗胜负。

失败代价：

- 驻地收益临时下降。
- 战备物资损耗。
- 资源点收益权转移。
- 不掉级，不爆付费道具，不摧毁宗门驻地。

## 七、阵营联动

玩家在化神 / 神躯阶段正式选择成仙、成魔或散修。宗门可选择立场，但玩家个人阵营与宗门立场冲突时，不能参与该宗门的阵营集结。

| 阵营 | 宗门任务倾向 | 九塔行为 | 结算奖励倾向 |
| --- | --- | --- | --- |
| 仙盟 | 护送、净化、修塔 | 镇封、补给、守塔 | 功德、民望、净魂玉 |
| 魔宗 | 袭塔、污染、献祭 | 破封、献祭、袭扰 | 魔印、血煞晶、九渊残晶 |
| 散修 | 情报、雇佣、资源 | 中立任务、平衡任务 | 纪元积分、资源、商票 |

阵营失衡补偿：

- 弱势方提高任务刷新数量。
- 弱势方获得 NPC 支援队列。
- 弱势方获得参与奖励补正。
- 不直接改变九塔胜负，不直接发放胜利奖励。

## 八、退宗与反套利

| 行为 | 冷却 / 限制 |
| --- | --- |
| 主动退宗 | 24 小时内不可加入新宗门 |
| 被踢出宗门 | 12 小时保护期，可申请新宗门 |
| 转宗 | 7 天内宗门战奖励衰减 |
| 立场切换 | 14 天冷却，需宗主发起、长老确认 |
| 仓库提取 | 入宗 72 小时后开放高价值提取 |

同设备、同 IP、异常账号组在宗门仓库、宗门战、PVP 刷分中触发风控衰减。

## 九、验收场景

- 宗门可在不固定在线的情况下完成任务、宗门战和九塔集结。
- 宗门职位权限明确，高危操作有日志。
- 宗门建设不消耗付费产物，不提供过高个人面板。
- 宗门战能影响资源点和州控制度，但失败不造成不可逆损失。
- 玩家个人阵营与宗门立场冲突时，不能参与该宗门阵营集结。
- 弱势阵营补偿提高参与收益，但不能制造必胜局。
