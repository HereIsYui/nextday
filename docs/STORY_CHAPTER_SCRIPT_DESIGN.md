# 《择日飞升：九塔封魔》章节剧本与剧情配置设计 v0.1

## 一、定位

本文把九州、九塔、仙魔阵营和最终魔王形态整理为可配置的章节剧本。目标是让剧情不只停留在世界观，而是能被任务、事件、公告、战报和结算文本调用。

## 二、剧情配置结构

| 字段 | 说明 |
| --- | --- |
| chapter_id | 章节 ID |
| chapter_name | 章节名 |
| day_range | 推荐天数范围 |
| province_unlock | 开放州域 |
| tower_focus | 重点封印塔 |
| npc_group | 主要 NPC |
| event_group | 章节事件 |
| branch_rule | 分支判断 |
| result_text_group | 结算文本 |
| next_chapter_gate | 下一章开放条件 |

## 五、魔王形态文本规则

| 九塔历史 | 魔王形态 | 叙事方向 |
| --- | --- | --- |
| 多塔重封 | 裂封魔王 | 魔王被封印撕裂，战斗多阶段、机制复杂 |
| 多塔攻破 | 九渊魔主 | 魔王完整降世，伤害和压迫感更强 |
| 仙魔拉锯 | 双相魔王 | 仙魔两相并存，最终战目标分裂 |

魔王必定出世，玩家改变的是：

- 魔王形态。
- 九州战场规则。
- 阵营优势。
- 结局文本。
- 称号和纪元史册。

## 六、剧情文本模板

章节开启：

```text
【{章节名}】
{州域}有异象再起，{封印塔}传来旧印回声。
诸位道友可前往九州地图提交行动，参与本章主线。
```

州事件结算：

```text
{州域}本轮事件已结算。
仙盟镇封：{fairy_value}
魔宗破封：{demon_value}
散修调停：{free_value}
州域状态变化：{state_change}
```

纪元史册：

```text
圣历一千一百四十五年，九塔复鸣。
本纪元魔王形态为「{demon_king_form}」。
{faction_result_text}
{top_player_text}
{sect_result_text}
```

## 七、验收场景

- 每章都有核心 NPC、州域、塔、玩家目标和分支影响。
- 剧情文本能被章节任务、州事件、公告和纪元结算复用。
- 成仙、成魔、散修都有结局文本入口。
- 魔王形态由九塔历史决定，但魔王必定出世。
- 剧情分支不改变付费强度边界，不发放唯一战力道具。
