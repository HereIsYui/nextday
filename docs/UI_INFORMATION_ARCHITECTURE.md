# 《择日飞升：九塔封魔》UI 信息架构 v0.2

> 2026-07-06 重策划说明：后续 Web 主界面以 [《九州城池纪元》重策划案](JIUZHOU_CITY_ERA_DESIGN.md) 为准。本文旧版“九州地图 + 今日任务 + 一键领取”结构保留为素材库，新首页应优先展示九州地图、我的城池、当前行军、可扩张目标、宗门 / 州战提醒和最近战报。

## 一、定位

本文定义游戏主要界面入口、信息层级和玩家日常路径。目标是让玩家进入游戏第一屏即可游玩，而不是看到营销页。

核心原则：

- 九州地图是核心导航。
- 日常任务和一键收菜保持高可见。
- 所有活动入口都支持随时参与，不强调固定时间在线。
- 付费、抽卡、概率和月卡权益表达清楚，不暗示付费必胜。
- 免费玩家也能在 30 分钟内完成核心收益。

## 二、主导航结构

主导航建议分为 6 个一级入口：

| 一级入口 | 说明 | 主要二级入口 |
| --- | --- | --- |
| 九州 | 大地图核心入口 | 州域、九塔、资源点、秘境、魔潮 |
| 修行 | 个人成长 | 修炼、突破、技能、法宝、丹药、炼器 |
| 洞府 | 经营生产 | 灵田、聚灵阵、丹炉、炼器室、内天地 |
| 宗门 | 社交组织 | 宗门任务、建设、仓库、宗门战、成员 |
| 事务 | 每日管理 | 任务、活动、邮件、公告、排行、成就 |
| 市肆 | 经济付费 | 交易行、抽卡、月卡、VIP、展示外观、充值预留 |

底部或侧边常驻快捷入口：

- 一键领取。
- 今日任务。
- 行动令。
- 背包。
- 战报。
- 设置。

## 三、第一屏信息

第一屏应直接展示玩家当前可做的事。

| 区域 | 内容 |
| --- | --- |
| 顶部状态栏 | 角色名、境界、修为进度、灵石、仙玉、行动令 |
| 中央主区 | 九州地图，当前州高亮，九塔状态可视化 |
| 右侧 / 下方任务栏 | 今日核心任务、推荐行动、一键提交 |
| 底部导航 | 九州、修行、洞府、宗门、事务、市肆 |
| 浮动提示 | 离线收益、可突破、可领取、战报 |

第一屏不展示营销大图，不用长篇世界观说明占据主操作区。世界观可放在剧情回顾、章节卷轴和图鉴中。

## 四、鱼排插件界面

鱼排聊天室插件默认不展示完整游戏面板，只展示一张小状态卡片。玩家点击卡片后，再以弹窗或抽屉打开复杂功能窗口。

默认小卡片：

| 区域 | 内容 | 交互 |
| --- | --- | --- |
| 当前状态 | 境界、修为进度、离线收益摘要 | 点击进入展开窗口 |
| 角色展示 | 称号样式、头像框 / 名片框、月卡状态 | 点击进入玩家名片或展开窗口 |
| 行动提醒 | 行动令接近上限、可领取、月卡赠抽状态 | 点击跳转对应模块 |
| 快捷操作 | 一键领取、默认预设提交、Web/H5 打开 | 仅限低风险白名单 |

展开复杂窗口：

| 模块 | 内容 |
| --- | --- |
| 今日日课 | 今日任务、可领取奖励、核心收益进度 |
| 洞府轻操作 | 一键收取、派遣摘要、生产提醒 |
| 九州 / 九塔 | 州状态、塔状态、可提交预设 |
| 战报 | 简化战报、PVP 防守、复仇提醒 |
| 古宝 / 月卡 | 月卡赠抽、残页抽取、古宝日课提醒 |
| 宗门 | 宗门任务、集结、仓库申请提醒 |

插件付费入口默认只展示状态和跳转，不在默认小卡片中承载鱼排积分扣减、复杂抽卡、交易行和高风险宗门管理。

## 五、九州地图

九州地图是主线、事件和异步活动入口。

| 地图元素 | 展示信息 | 交互 |
| --- | --- | --- |
| 州域节点 | 开放状态、魔染、民望、灵脉等级 | 点击进入州详情 |
| 封印塔 | 完整度、裂隙压力、镇封 / 破封趋势 | 进入九塔行动 |
| 资源点 | 控制度、驻守状态、收益权 | 进攻、驻守、查看战报 |
| 秘境 | 解锁层数、剩余秘境令 | 挑战、扫荡 |
| 魔潮 / Boss | 阶段血量、个人贡献 | 挑战镜像、领取奖励 |
| 奇遇点 | 剩余时间、推荐境界 | 探索、派遣 |

九州地图需要提供筛选：

- 今日推荐。
- 可领取。
- 可提交行动。
- 宗门集结。
- 阵营任务。
- 新手追赶。

## 六、任务与活动面板

任务面板要回答三个问题：今天做什么、还差多少、点哪里完成。

结构：

| 页签 | 内容 |
| --- | --- |
| 今日 | 日常任务、活跃度、核心收益进度 |
| 周常 | 周任务、剩余周期、可追回行动 |
| 章节 | 当前章节目标、服务器主线进度 |
| 九州 | 各州事件、九塔任务、州状态 |
| 活动 | 节日、回归、补偿、运营活动 |

每条任务显示：

- 任务名。
- 当前进度。
- 推荐入口。
- 预计耗时。
- 奖励预览。
- 是否计入 30 分钟核心收益。
- 是否支持一键提交。

## 七、修行与战斗入口

修行页：

- 境界进度。
- 修为 / 气血精元收益。
- 突破成功率和劫气保底。
- 当前追赶加成。
- 推荐丹药和天象。

战斗页：

- 技能配置：3 个主动技能、1 个本命法宝技能、自动优先级。
- 自动 / 半自动 / 手动关键技设置。
- 战斗日志、胜负原因、伤害和承伤摘要。
- PVP 防守镜像配置。

战斗结果页必须展示：

- 消耗行动令。
- 贡献。
- 掉落。
- 战斗日志入口。
- 风控或收益衰减原因。

## 八、洞府与生产入口

洞府页强调“5 分钟收菜”。

| 模块 | 关键信息 |
| --- | --- |
| 灵田 | 成熟时间、一键收获、种植队列 |
| 聚灵阵 | 离线收益缓存、升级材料 |
| 丹炉 | 可炼丹药、丹阶、品质概率、自动炼丹策略 |
| 炼器室 | 器胚、词条、炉运、铭刻锁定 |
| 内天地 | 派驻州、收益、风险、召回 |

自动消耗策略入口必须明确显示保留数量、禁止消耗品类和手动确认规则。

## 九、宗门入口

宗门页要服务异步组织，不依赖固定在线。

| 模块 | 关键信息 |
| --- | --- |
| 宗门总览 | 等级、立场、成员、驻地、公告 |
| 宗门任务 | 今日任务、成员贡献、可一键提交 |
| 宗门建设 | 建设项目、材料需求、进度 |
| 宗门仓库 | 白名单、额度、审批、日志 |
| 宗门战 | 进攻队列、防守镜像、战报、周期结算 |
| 九塔集结 | 宗门推荐塔、行动预设、成员贡献 |

权限操作如踢人、立场切换、仓库审批必须二次确认并写日志。

## 十、市肆、抽卡与付费入口

市肆包含交易行、抽卡、月卡、VIP 和充值预留。

抽卡页必须展示：

- 卡池名称。
- 消耗类型。
- 概率公示入口。
- 保底进度。
- 抽取历史。
- 绑定仙玉是否可用。
- 纪元继承规则。

九大古宝专属池额外展示：

- 只产出九大古宝。
- 小月卡每日 1 抽，大月卡每日 2 抽。
- 月卡赠抽当日有效。
- 支持九大古宝残页合成抽取。
- 付费仙玉直抽为后期预留入口，当前应隐藏或标记“暂未开放”，不能点击扣费。
- VIP 不提供古宝抽取次数。
- 重复古宝转化规则。

月卡 / VIP 页：

- 月卡价格使用鱼排积分。
- VIP 只读取鱼排等级和有效期。
- VIP3 可等同小月卡便利，VIP4 可高于小月卡但不超过大月卡。
- 月卡付费仙玉和古宝赠抽是月卡资产，不属于 VIP。

## 十一、背包、邮件和公告

背包筛选：

- 材料。
- 丹药。
- 法宝。
- 古宝。
- 任务物品。
- 纪元收藏。
- 展示外观。
- 付费 / 绑定。

道具详情必须显示：

- 绑定状态。
- 是否可交易。
- 来源。
- 过期时间。
- 是否可自动消耗。
- 纪元继承规则。

展示外观入口：

| 展示位置 | 可展示内容 | 说明 |
| --- | --- | --- |
| 玩家名片 | 称号样式、头像框 / 名片框、洞府外观、图鉴外观 | 作为个人身份展示主入口 |
| 排行榜 | 称号样式、头像框、纪元史册外观 | 只展示荣誉，不显示战力暗示文案 |
| 宗门 | 宗门外观、宗门牌匾、成员名片框 | 宗门外观不提高宗门建设或战斗收益 |
| 战报 | 战报样式、发言前缀、称号样式 | 不改变战斗结果和奖励结算 |
| 聊天 | 聊天气泡、发言前缀、称号样式 | 控制视觉占用，避免影响阅读 |
| 鱼排插件小卡片 | 称号样式、头像框 / 名片框、月卡展示态 | 默认小卡片只显示轻量展示，不默认展开商城 |
| 纪元史册 | 纪元史册外观、纪元纪念物、终局记录样式 | 可跨纪元继承展示，不继承战力 |

展示外观只影响界面展示，不提高攻击、防御、PVP 伤害、九塔贡献倍率、资源掉落和全服胜负能力。

邮件和公告：

- 邮件分为系统、补偿、订单、排行、宗门。
- 公告分为维护、活动、概率、规则调整、风控说明。
- 涉及概率、补偿和规则变化时，必须有清晰入口可回看。

## 十二、红点和提醒规则

红点优先级：

| 优先级 | 场景 |
| --- | --- |
| 高 | 离线收益满、行动令接近上限、奖励即将过期 |
| 中 | 可突破、可领取任务、宗门审批、战报复仇 |
| 低 | 图鉴解锁、称号获得、外观更新 |

红点约束：

- 不用红点强迫付费。
- 不对已明确忽略的低优先级入口反复提示。
- 付费入口红点只用于已购买权益可领取、月卡即将到期，不用于制造焦虑。

## 十三、九州城池重构界面目标

新首页第一屏必须回答四个问题：

- 我出生在哪一州，主城在哪里。
- 我现在能占哪块地、打哪个资源点、守哪里。
- 我的队伍在哪里，多久到达。
- 我的州、宗门和城池正在发生什么。

桌面主界面建议：

| 区域 | 内容 | 交互 |
| --- | --- | --- |
| 顶部状态栏 | 角色、主城等级、出生州、资源、队列数量 | 点击资源查看产销 |
| 左侧主区 | 九州 / 郡域地图、地块、资源点、关隘、九塔 | 点击地块切换详情 |
| 中央详情 | 当前选中地块、守军、产出、归属、可执行动作 | 侦查、行军、占领、驻防 |
| 右侧侧栏 | 我的主城、行军队列、最近战报、宗门提醒 | 快速回城、查看队列、回放战报 |
| 底部功能 | 城建、军队、修行、宗门、市肆、史册 | 点击后只展开对应功能 |

信息层级调整：

- “今日修行”改名为“今日战略建议”，只推荐城建、占领、驻防、州战等关键行动。
- 功能按钮不再堆在页面底部导致玩家向下找内容，点击功能后在主工作区替换内容。
- 九塔作为地图奇观展示在对应州域，不再作为固定日课入口。
- 修行、炼丹、炼器放入城池 / 军队补给路径中，不再抢地图主视线。
- 战报默认展示行军、清野、攻城、占领、防守结果，旧探索战报作为战报类型之一保留。

城池状态必须玩家化表达：

| 状态 | 玩家文案 |
| --- | --- |
| protected | 免战保护中 |
| damaged | 城防破损 |
| besieged | 正在被围困 |
| vassal | 附庸恢复期 |
| contested | 争夺中 |
| occupied | 已占领 |

## 十四、验收场景

- 玩家第一屏能看到九州地图、我的主城、当前行军、可占领目标和最近战报。
- 玩家 30 分钟内能通过任务面板完成核心收益。
- 任意活动入口都能说明可提交行动、剩余周期和结算规则。
- 抽卡页能查看概率、保底、历史和纪元继承规则。
- 九大古宝专属池清楚展示只产出九大古宝。
- 九大古宝专属池只展示月卡赠抽和残页合成入口；仙玉直抽入口只能作为暂未开放的预留状态。
- 鱼排插件默认只显示小状态卡片，复杂功能必须点击后展开。
- 展示外观能在玩家名片、排行榜、宗门、战报、聊天、鱼排插件小卡片和纪元史册中展示，但不改变奖励、战斗和贡献结算。
- 宗门权限、仓库审批、付费操作都有二次确认和日志入口。
- 免费、VIP、月卡的便利差异体现在操作效率，不体现在奖励倍率。
- 功能按钮点击后在主工作区切换对应功能，不要求玩家向下滚动寻找内容。
